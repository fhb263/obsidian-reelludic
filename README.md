## 这是什么

ReelLudic是一个 Obsidian 插件，把六类收藏（电影 / 电视剧 / 动画 / 书籍 / 游戏 / 音乐）变成库中可管理、可追踪、可双链的结构化资产，并内置阅读器与播放器，让收藏真正可看、可读。

**核心理念：一切收藏都以 Markdown + JSON 落盘，原生融入双链笔记生态。**
- `catalog.json` 是**结构化事实源**（目录元数据）
- 每条目自动生成 Markdown **详情笔记**（frontmatter + 属性表 + 简介/评语/链接章节），可手动批注、可被任意笔记双链引用
- 笔记里改的内容（正文章节 / frontmatter / 来源链接）打开编辑表单时**自动回填**，表单保存后笔记再同步生成——双向一致
- 阅读数据（进度 / 书签 / 高亮）按「**一本书一个 JSON**」存放，与笔记解耦；笔记里的「## 高亮」区是插件生成的可读镜像（摘抄照旧写在笔记的「## 摘抄」区）

## 安装

### 方式一：BRAT 安装

1. 在 Obsidian 中安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件
2. 打开 BRAT 设置 → 点击 **Add Beta plugin** → 输入仓库地址：
   ```
   https://github.com/fhb263/obsidian-reelludic/
   ```
3. 安装完成后，在 设置 → 第三方插件 → 启用 **ReelLudic**

### 方式二：手动安装

1. 从本仓库的 [Releases](https://github.com/fhb263/obsidian-reelludic/releases) 下载最新版本的三个文件：`main.js`、`styles.css`、`manifest.json`
2. 复制到你的 Vault 目录下：`<你的Vault>/.obsidian/plugins/obsidian-reelludic/`
3. 重启 Obsidian → 设置 → 第三方插件 → 启用 **ReelLudic**

## 使用方法

### 配置数据源

| 类型       | 默认源链 | 可自选补充源                    |
| -------- | ---- | ------------------------- |
| 书籍       | 豆瓣   | Open Library、Google Books |
| 漫画       | 豆瓣   | Bangumi、MangaDex          |
| 游戏       | 豆瓣   | Steam、IGDB                |
| 音乐       | 豆瓣   | MusicBrainz、iTunes        |
| 电影 / 电视剧 | 豆瓣   | TMDB、OMDb                 |
| 动画       | 豆瓣   | Bangumi、AniList           |

- 豆瓣是每类链首的主力源，需填登录态 Cookie（做法见 FAQ）；补充源（TMDB / OMDb / Bangumi / IGDB）在 设置 → 元数据源配置 填 Key 并「测试连接」，免 Key 源（Open Library、Steam、MusicBrainz、iTunes、AniList、MangaDex）可直接用。
- 源链可自选、可排序，默认链之外的源勾选后才参与搜索；搜索框下方实时列出每个源的状态，单源失败不影响其他源。

### 添加条目

1. 点工具栏「＋ 添加」（或命令面板「添加条目」）。
2. 输入标题即自动搜索当前类型的数据源，选中结果回填标题 / 封面 / 年份 / 评分 / 简介；没命中也可手填。
3. 新增时另有一行四个框（**来源**、**大众评分**、**评价人数**、**平台链接**），填完右侧立刻预览「来源名 + 评分★」；编辑时这行以只读文字显示，**右键**可改。
4. 保存后写入 `catalog.json`，并在 `笔记/` 下按类型（书籍再按子分类）生成详情笔记。

### 日常管理

- **状态流转**：想看 / 在看 / 已看 / 存档（音乐为 想听 / 在听 / 已听 / 存档），在卡片菜单或编辑表单里切换。
- **视图与筛选**：海报墙 / 列表 / 瀑布流；按类型、书籍分类、状态、排序、题材（多选）筛选。
- **分页与批量**：每页 48 条；勾选多条目后底部可批量改状态 / 评分 / 标签。
- **封面**：右键封面可更换 / 重新下载 / **从网络搜索一张**；也可把本地图片拖进编辑表单。封面存于 `封面/`。
- **AI 摘要**：编辑表单标题旁 ✨ 生成「一句话总结 + 核心看点」并写入笔记；在笔记里手改也会被表单读回。
- **AI 预填**：新增条目走「手动填写」时，标题旁 ✨ 列出**客观字段**（年份 / 题材 / 作者 / 出版社 / 主演 / 平台 / 简介等）—— **先出建议清单、点「回填」才写入**；先查元数据源、再联网搜索，查不到才凭记忆（简介优先照抄源站原文）。状态 / 评分 / 笔记 / 进度等个人字段不碰。
- **系列折叠卡**：同一类型下同名系列 ≥2 条自动叠成一张卡（错位窄边 + 类型色描边 + ×N 角标，**尺寸与普通卡一致**）。点卡片本体进「只看这一个系列」；点右下角圆钮弹出封面网格，挑一部接着看 / 读。

### 阅读器（书籍 / PDF）

关联了本地 TXT / EPUB / PDF 的条目，▶ 打开**内置阅读器**（需先开 设置 → 基本设置 › 实验性功能 →「内置阅读器打开书籍文件」，否则交给系统程序）。

- **界面**：标签页打开、可并排；六档阅读主题；左侧目录栏（可拖宽、可收起）；顶栏六个入口（书签 / 高亮 / 摘抄 / 翻译 / 网络搜索 / AI 搜索），窗口窄时收进「更多」。
- **排版**：滚动 / 翻页、字体、字号、行距、行宽、首行缩进，改完立即生效。
- **摘抄与高亮**：选中文字弹卡片写摘抄（Ctrl / ⌘ + Enter 保存，支持双链），高亮三样式 × 五色；侧栏「目录 | 摘抄」两页签，摘抄页里书签 / 高亮 / 摘抄三区叠放。
- **回到原文**：点笔记里摘抄 / 高亮的头行链接，即打开阅读器并定位到那一句。
- **听书与划词搜索**：系统语音朗读本章（点任意一段从该段读起），或切云端音色（需在 设置 → AI 集成 填 Key）；选中文字可走 25 个引擎的网络搜索，或让 AI「解读选段 / 自定义提问」。

### 播放器（影视 / 动画）

- **标签页播放**：点「观看」在标签页播放，可选集、调倍速 / 音量、全屏；控制条鼠标停住 1 秒自动收起。
- **本地视频与字幕**：需先开 设置 → 基本设置 › 实验性功能 →「内置播放器打开视频文件」；同目录的 `.srt` / `.vtt` 自动挂载，mkv 等格式转交系统播放器。
- **进度条打点**：插过时间戳 / 截过图的位置显示圆点，点圆点跳转、悬停出卡片，右键打开视频笔记并跳到那一行。
- **快捷键**：T 时间戳、S 截图（笔记开到右侧分屏）；空格播放 / 暂停、←→ 前后 5 秒、↑↓ 音量、M 静音、F 全屏。
- **播放策略**：播完可选 切下一集 / 循环本集 / 暂停；支持后台播放与记忆播放位置。
- **从 B站 填链接**：条目「网络地址」旁的放大镜按「标题 + 集标题」搜 B站。命中**多P 视频**时展开分P 勾选表（一行一集，默认只勾「还没填链接」的集，多出的分 P 置灰），勾完整季一次填完；单P 视频直接填这一条。

### 游戏与音乐

- **游戏**：关联 `.lnk` 快捷方式后 ▶ 直接启动；「记录游玩」录入时长与心得（统计页累计）。
- **音乐**：关联本地音频后 ▶ 播放；在「播放」上右键可改这个音频（及同名歌词）文件的文件名。
  - **LRC 歌词**：编辑条目点「获取歌词」到四个源并行搜索，选中即填入，也可直接粘贴自己的 LRC；音乐笔记的 `lrc` 块可与 LyricFlux 侧边栏播放联动。
  - **AI 双语歌词**：LRC 框旁的小按钮把歌词**逐行**译成中文（`[00:15.16]hello | 你好`，时间标签不动，已有译文跳过），走「AI集成 › 用途 · 翻译服务」的服务商与 Key。
  - **B站 下载**：设置 → 元数据源配置 › 音乐源凭据 里的 **yt-dlp 路径**（留空走系统 PATH）把 B站 视频转 mp3（另需 ffmpeg）。

### 追更与排期

- 连载中的剧集 / 动画标记「在看」即进入**追番表**：自动检测最新集数并提示更新，按活跃度排序。
- 「计划」页签可在 追番表 / 排期表 间切换；**排期表**把左侧「待排期」卡片拖到日期格即可排期，到期未开始的条目出现在顶部横幅。

### 统计与报告

统计页分三层：**核心指标 → 动态 / 趋势 → 分类概览**。

- **核心指标**：1 个主指标（今年看完，附与去年对比）+ 4 个小指标（本月看完、在追 / 在读、本月计划、库内总数）；主指标卡内可一键生成年度报告，之后可回看历年。
- **动态**：切 日 / 周 / 月 / 年 查看这段时间看了什么、追到哪一集；右侧记录按钮把当前范围写成打卡区块放进**当天日记**。
- **趋势与概览**：月度看完趋势图（图例可点：全部 / 书籍 / 影视 / 游戏 / 音乐）+ 分类概览（书籍 / 影视 / 游戏 / 音乐 Tab，各 4 指标 + Top 3），窄面板自动上下堆叠。

### 数据目录

所有数据存放在 vault 内一个目录（默认 `ReelLudic/`，可在 设置 → 基本设置 › 数据与备份 → 媒体库目录 改名）：
```
ReelLudic/
├── catalog.json           # 结构化事实源（条目元数据）
├── catalog-backups.json   # 自动滚动备份（单文件，含最近 5 版）
├── 封面/                  # 本地化封面（封面/{标题}.jpg）
├── 笔记/                  # 详情笔记
│   ├── movie/ teleplay/ animation/ game/ music/
│   └── book/ novel/ comic/   # 书籍按子分类分目录（文学 / 网文 / 漫画）
├── 阅读进度/              # 每本书一个 JSON：进度 + 书签 + 高亮
├── 备份/                  # 设置页手动导出的 catalog 快照
└── 报告/                  # 年度总结
```

## 界面外观

打开插件，第一眼看到的是**书架主界面**——一部部「藏品」以封面卡片排满页面。从上到下依次是：

- **顶部页签栏**：计划 / 阅读 / 影视 / 游戏 / 音乐 / 统计 六个页签，点击切换收藏空间
- **搜索行**：搜索框按标题实时筛库（Esc 清空）；右侧是「＋ 添加」与库内总数
- **筛选行**：类型胶囊 / 书籍分类胶囊（阅读页签专属：全部 · 文学 · 网文 · 漫画）+ 状态下拉 + 排序下拉 + 题材 + 右侧 ▦ ☷ ▥ 视图切换（音乐多一个 ☰ 分组歌单）
- **书架主体 · 海报墙**（默认视图）：一行行 2:3 封面卡片，卡片含标题、原名 / 年份、创作者、题材、进度（书籍显示阅读百分比与进度条），底部是状态徽标 + 我的评分 ★，封面右上角是大众评分小标签（悬停可见数据源）
- **卡片悬停快操作**：封面右上「⋯ 更多」、封面下方「打开笔记 ↗」、右下圆形 ▶（观看 / 阅读 / 播放 / 启动，随类型变化）；卡片上**右键**出同款菜单
- **勾选条目后**底部浮现批量操作栏（状态 / 评分 / 标签 / 应用 / 删除 / 取消选择）
- **视图切换**：海报墙（封面卡片墙）/ 列表（带排序表头的表格，表头可全选本页）/ 瀑布流（纵向无缝图墙）
- **计划页签**：追番表与排期表（月 / 周日历，左侧「待排期」可拖到日期格）
- **统计页签**：三层结构 —— 核心指标（1 主 4 辅，年度报告入口在主指标卡里）→ 动态 → 月度趋势与分类概览（左右并排，窄窗口自动堆叠）
- 页面右下角还有一个「回到顶部 ↑」悬浮小圆钮

在书架里点 ▶ 或从右键菜单进入，还能看到**编辑器、阅读器与播放器界面**：书籍会打开内置阅读器（TXT / EPUB / PDF），影视本地视频用内置播放器，游戏一键启动 `.lnk` 快捷方式。

## 设置页

顶部是 **4 个平级入口**（切页时顶栏固定不动，只有下面的内容区滚动）：

- **基本设置**：外观与体验（隐藏插件内滚动条）· 实验性功能（内置阅读器 / 内置播放器 / 音频播放三条开关，关闭时交还系统程序）· 数据与备份（媒体库目录、笔记表格开关、数据备份与恢复）· 封面与清理（下载封面、附件清理）
- **元数据源配置**：元数据源凭据（各源凭据填写与「测试连接」）+ 音乐源凭据（下载用 Cookie，末行为 **yt-dlp 路径**）+ 元数据源启用（每类型源链的选择与排序，含**漫画**）—— 凭据排在「启用」之前
- **AI集成**：AI服务（**翻译 / 总结 / 搜索 / 预填 / 歌词双语** 五套的服务商、模型与提示词各自可调；末尾是朗读音源）· API凭据（智谱清言 / DeepSeek / **自定义端点** / 硅基流动的 Key 与「测试连接」）
  - ⚠️ **歌词双语走「翻译服务」那一套**（服务商 + 模型），不单开凭据；其提示词内置（逐行对齐是格式要求，不可改）。
- **关于**：插件版本与作者信息 · 问题反馈 / 更新日志入口（更新日志 = 插件内弹窗，一个版本一句话）· 支持作者

## 常见问题（FAQ）

### 点 ▶ 打开的是系统程序，不是内置阅读器 / 播放器

内置阅读器与内置播放器都是**默认关闭**的实验性功能，开关在 设置 → 基本设置 › 实验性功能：「内置阅读器打开书籍文件」打开后 TXT / EPUB / PDF 在标签页里读；「内置播放器打开视频文件」打开后本地视频在插件播放器里播。关闭时交还系统程序。

⚠️ 例外：**笔记里的深链永远走内置**（点笔记里的时间戳链接、阅读器头部链接）——只有内置阅读器 / 播放器能定位到「第几秒」「哪一句」。

### 搜不到东西，或某一源显示「请求失败」

搜索框下方会列出**每个源的实时状态**——单个源失败不影响其他源。按顺序排查：

1. **豆瓣是每类默认的主力源，必须配 Cookie。** 到 设置 → 元数据源配置 › 元数据源凭据 → **Douban Cookie**，登录 douban.com 后按 `F12` → Network → 复制任意请求的 `Cookie`（**必须含 `dbcl2` 登录态**）粘贴进去。
2. **豆瓣密集搜索会被风控。** 短时间反复搜索容易被判为爬虫，表现为「请求失败」或空结果，等几分钟再试。
3. **给每类补一个免 Key 的第二源**：书籍 → Open Library、Google Books；漫画 → MangaDex（默认已在链里）；游戏 → Steam；音乐 → MusicBrainz、iTunes；动画 → AniList。
4. **需要凭据的源要先填 Key**：TMDB、OMDb、Bangumi、IGDB（需要 Twitch 的 Client ID 与 Client Secret **两个值**）。填完点「测试连接」。
5. **网络不可达**。除豆瓣外的源服务器多在境外，网络不通时同样显示「请求失败」。

### 封面不显示 / 一片空白

- 豆瓣图床有防盗链，浏览器里能看、插件里下载会被拒。插件会在**选中结果时把封面下载到本地** `ReelLudic/封面/{标题}.jpg`；下载失败会退回远程 URL，部分环境下就是空白。
- **手动补封面**：编辑表单里**把本地图片拖到封面区**，或**右键封面 → 更换封面**；**批量修**可走 设置 → 基本设置 › 封面与清理 → **下载封面**。
- **换过媒体库目录后**封面路径会失效（封面按库相对路径存放，换库不会自动搬图）。
- **清理残留**：设置 → 基本设置 › 封面与清理 → **附件清理**，列出没被引用的封面与遗留阅读存档，逐项勾选后再删除。

### 数据备份、导入导出与迁移

- **自动备份**：每次改动数据前，插件把上一版 `catalog.json` 存进 `ReelLudic/catalog-backups.json`——**一个文件**内含最近 5 版（内容没变化时不重复存）。
- 设置 → 基本设置 › 数据与备份 → **数据备份与恢复**：导出生成 `catalog.json` 快照（存 `备份/`）；导入按「标题 + 类型」判重合并，**不会覆盖已有条目**。
- **迁移到新电脑 / 新库**：整个 `ReelLudic/` 目录拷过去即可，搬完检查 媒体库目录 是否指向正确位置。
- 详情笔记是普通 Markdown，可被任意笔记双链引用，也可直接手改——**手改的内容在下次打开编辑表单时会被读回**。

### 本地视频黑屏 / 没声音

内置播放器走 Chromium 解码，只稳定支持 **mp4 / webm / mov / ogv**。mkv、avi、flv、wmv 等容器，或 HEVC、AV1 等编码，会黑屏或无声——这类文件会被自动转交给系统播放器。想一律用外部播放器，关掉「内置播放器打开视频文件」即可。

### 追番表检测不到最新集数

更新检测的原理是**抓取条目关联的观看网址页面**、从中提取集数，再与已看进度相减。所以：条目必须关联网页链接；链接页面里要有可识别的集数信息；站点改版或页面结构变化会导致抓取失效。
