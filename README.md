> 把媒体信息管理与播放阅读于一体的Obsidian插件。通过元数据自动获取媒体信息，支持关联网页链接和本地文件，内置阅读器与播放器，让你轻松管理多媒体笔记。

---

## 这是什么

ReelLudic是一个 Obsidian 插件，把六类收藏（电影 / 电视剧 / 动画 / 书籍 / 游戏 / 音乐）变成库中可管理、可追踪、可双链的结构化资产，并内置阅读器与播放器，让收藏真正可看、可读。

<img width="1143" height="949" alt="image" src="https://github.com/user-attachments/assets/507061bd-d148-4c15-8254-efab39403594" />


**核心理念：一切收藏都以 Markdown + JSON 落盘，原生融入双链笔记生态。**
- `catalog.json` 是**结构化事实源**（目录元数据）
- 每条目自动生成 Markdown **详情笔记**（frontmatter + 属性表 + 简介/评语/链接章节），可手动批注、可被任意笔记双链引用
- 笔记里改的内容（正文章节 / frontmatter / 来源链接）打开编辑表单时**自动回填**，表单保存后笔记再同步生成——双向一致
- 阅读数据（进度 / 书签 / 高亮）按「**一本书一个 JSON**」存放，与笔记解耦；笔记里的「## 高亮」区是插件生成的可读镜像（摘抄照旧写在笔记的「## 摘抄」区）

## 安装

### 方式一：BRAT 安装

1. 在 Obsidian 中安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件
2. 打开 BRAT 设置 → 点击 **Add Beta plugin** → 输入仓库地址：
   ```
   https://github.com/fhb263/obsidian-reelludic/
   ```
3. 安装完成后，在 设置 → 第三方插件 → 启用 **ReelLudic**

### 方式二：手动安装

1. 从本仓库的 [Releases](https://github.com/fhb263/obsidian-reelludic/releases) 下载最新版本的三个文件：
   - `main.js`
   - `styles.css`
   - `manifest.json`
2. 将这三个文件复制到你的 Vault 目录下：
   ```
   <你的Vault>/.obsidian/plugins/obsidian-reelludic/
   ```
3. 重启 Obsidian → 设置 → 第三方插件 → 启用 **ReelLudic**

## 使用方法

### 配置数据源

| 类型       | 默认源链   | 可自选补充源                    |
| -------- | ------ | ------------------------- |
| 书籍       | Douban | Open Library、Google Books |
| 游戏       | Douban | Steam、IGDB                |
| 音乐       | Douban | MusicBrainz、iTunes        |
| 电影 / 电视剧 | Douban | TMDB、OMDb                 |
| 动画       | Douban | Bangumi、AniList           |

- **豆瓣是每类链首的主力源，需要填写登录态 Cookie**（做法见下方 FAQ）。其余源按需在 设置 → 数据源配置 › 数据源凭据 里填 Key 后点「测试连接」。
- **源链可以自己排**：设置 → 数据源配置 › 数据源启用 里选每类用哪几个源、谁在前。默认链之外的源（Google Books / OMDb / AniList / IGDB 等）勾选后才参与搜索。
- 搜索时**每个源的状态实时列在搜索框下方**，单个源失败不影响其他源。

### 添加条目

1. 点击工具栏的「＋ 添加」（或命令面板执行「添加条目」）；在「阅读」页签聚焦「文学 / 网文」时，新增表单会默认带上下拉里那一类
2. 输入标题后自动从当前类型的数据源搜索——选中结果即回填标题 / 封面 / 年份 / 评分 / 简介等元数据；没有命中也可手动填写
3. 保存后生成两样东西：`catalog.json` 里的结构化条目，以及 `笔记/` 下按类型分目录的详情笔记（Markdown，可被任意笔记双链引用；更新插件后旧笔记自动迁移）

### 日常管理

- **状态流转**：在卡片 / 列表的操作菜单或编辑表单中切换 想看 → 在看 → 已看 → 存档（文案随类型变化：想读 / 在读、想玩 / 在玩、想听 / 在听）
- **浏览与筛选**：右上角切换 海报墙 / 列表 / 瀑布流 三种视图（音乐另有分组歌单视图）；类型与书籍分类是带计数的胶囊，状态与排序是下拉，列表可按列排序；**题材**是视图级筛选（题材池按当前视图汇总，只列这个视图里出现过的题材，可多选，面板里可一键全选 / 清空）
- **分页**：条目超过一页时（每页 48 条）底部出现页码条，翻页后自动回到顶部
- **批量**：勾选多个条目后，底部批量栏可统一改状态、评分、追加标签；列表表头的全选框只选当前页，跨页勾选会保持
- **封面**：右键封面可更换 / 重新下载，也可把本地图片拖进编辑表单的封面区；封面统一存于 `封面/{标题}.jpg`，设置页可一键下载 / 清理未被引用的孤儿封面
- **AI 摘要**：编辑表单标题旁 ✨ 让 AI 生成「一句话总结 + 核心看点」（也可完全手填），结果写入笔记对应章节；在笔记里手改也会被表单读回

### 阅读器（书籍 / PDF）

关联了本地 TXT / EPUB / PDF 文件的条目，▶ 会打开**内置阅读器**（需在 设置 → 基本设置 › 实验性功能 打开「内置阅读器打开书籍文件」，否则仍交给系统默认程序）。

- **三种格式，标签页打开**：TXT / EPUB / PDF 都在 Obsidian 标签页里阅读——可以并排看两本书、拖到别的窗口，关闭就是关标签页
- **六档阅读主题**：跟随主题（默认）/ 经典白 / 夜间黑 / 护眼绿 / 深灰 / 羊皮纸；切换后顶栏、目录栏、正文、底栏与设置菜单整体换肤，PDF 同样可选
- **目录栏**：最左侧一整列，可拖宽（宽度会记住）、可收起；每章后面显示**阅读量**（中文按字、英文按词）
- **顶栏**：中间显示当前章节（如「第三章：风起」）；书签 / 高亮 / 摘抄 / 翻译 / 网络搜索 / AI搜索 六个快捷入口，窗口不够宽时整排收进「更多」菜单
- **排版可调**：阅读模式（连续滚动 / 翻页）、字体、字重、字距、字号、行距、行宽、首行缩进；字号与行距是滑条，改完立即生效；正文版心随窗口宽度与字号自适应，首行缩进两字默认开启
- **底栏开关**（点一下即开、再点即关，「自动」与「朗读」右键可调细节）：TXT / EPUB 有 全屏 / 沉浸 / 自动 / 朗读 四个，PDF 有 全屏 / 沉浸 / 自动 三个；底栏另显示全书进度（悬停可见「章内 X% · 全书 Y%」）
- **摘抄**：选中文字后就地弹出小卡片写入（Ctrl / ⌘ + Enter 保存），可写想法、支持双链；保存后笔记里生成 callout 卡片（头行是带章节与位置的源文件链接，写了想法的原文会加粗）
- **高亮**：三种样式（高亮 / 划线 / 波浪）× 五种颜色，点一下就换并记住作为默认；同一段再点一次「高亮」即取消（PDF 阅读器不含高亮）
- **同一列兼作标注栏**：侧栏底部是 目录 | 摘抄 两个页签 —— 摘抄页里 书签 / 高亮 / 摘抄 三区上下叠放，每区都有「清除全部」；动作条上也有垃圾桶可直接删除选中的高亮与摘抄
- **点笔记里的头行链接可回到原文**：打开（或复用）这本书的阅读器并定位到那一句；落点按引用文字匹配，换字号、改窗宽、换设备都不会跑偏
- **听书**：用电脑自带语音朗读本章，不联网、不用配置；点正文任意一段即从该段读起，朗读时当前句变灰并自动滚到屏幕中间；语速、音调、音量就地可调且不打断朗读；也可切到云端音色（音色更饱满，需先在 设置 → AI集成 › API凭据 · 硅基流动 填一个 Key）
- **划词搜索**：选中文字后可**网络搜索**（25 个引擎，按通用 / 垂直 / 特色 / 购物 / 学术五组，多数用各站官方图标）或 **AI 搜索**（「解读选段」或「自定义提问」，先给结论再列要点）；结果页在系统默认浏览器打开

### 播放器（影视 / 动画）

- **标签页播放**：点条目的「观看」在 Obsidian 标签页里播放，可选集、调倍速（0.5×–2×）、调音量、全屏；控制条收成一整行（选集 / 倍速 / 字幕 / 音量 / 设置 / 全屏），鼠标停住 1 秒自动收起；画面撑满内容区并按原始宽高比显示
- **本地视频**：需在 设置 → 基本设置 › 实验性功能 打开「内置播放器打开视频文件」（默认关闭，关闭时交给系统播放器）；只稳定支持 mp4 / webm / mov / ogv，mkv 等 Chromium 不可解的格式会自动转交系统播放器
- **字幕**：视频同目录的 `.srt` / `.vtt` 自动挂载，也可从列表或任意位置选择，随时可关
- **进度条打点**：视频里插过时间戳、截过图的位置会在进度条上显示小圆点；点圆点跳到该秒，悬停浮出小卡片（类型、时刻、你写的说明、截图缩略图），在圆点或卡片上**按右键直接打开视频笔记并跳到那一行**；你手写在「## 时间戳」区里的行也会被识别成一个点
- **插入时间戳（按 T）**：把当前时刻写成笔记里一条可点的链接，点一下就跳回视频那一刻并开始播放
- **一键截图（按 S）**：截下当前画面存进附件目录，并连同一条回到视频的时间戳写进笔记的「## 截图」区；插入时间戳或截图时，视频笔记会自动开在右侧分屏（不抢焦点、视频继续播）
- **播放策略**：播完可选「切下一集 / 循环本集 / 暂停」；支持后台播放（切走标签页也继续播）与记忆播放位置（关掉再打开接着上次继续）
- **快捷键**：空格播放 / 暂停、←→ 前后 5 秒（按住 Shift 为 30 秒）、↑↓ 调音量、M 静音、F 全屏、T 插入时间戳、S 截图

### 游戏与音乐

- **游戏**：关联 `.lnk` 快捷方式后 ▶ 直接启动；「记录游玩」可录入游玩时长与心得（统计页会累计）
- **音乐**：关联本地音频后 ▶ 播放（vault 内音频用 Obsidian 媒体视图播放，库外回退系统播放器）；音乐笔记的 `lrc` 模板可与 LyricFlux 侧边栏播放联动

### 追更与排期

- 把连载中的剧集 / 动画标记为「在看」即进入**追番表**：自动检测网站最新集数并提示更新，按活跃度排序
- 「计划」页签可在 追番表 / 排期表 之间切换；**排期表**是日历视图（右上角可切 月 / 周），可为条目设定计划观看日期，把左侧「待排期」卡片拖到日期格即可排期；到期未开始的条目出现在顶部横幅，点「开始观看」一键转入在看

### 统计与报告

统计页签分三层：**核心指标 → 动态 / 趋势 → 分类概览**。

- **核心指标**：1 个主指标（今年看完，附与去年的对比）+ 4 个小指标（本月看完、在追 / 在读、本月计划、库内总数）；「生成今年总结 / 往年报告」两个按钮就在主指标卡内，一键产出年度报告，之后可随时回看历年总结
- **动态**：可切 日 / 周 / 月 / 年 查看这段时间看了什么、追到哪一集；**日**视图逐条列出（几点几分、什么状态、《哪部》）；**周 / 月 / 年**改为周期汇总并逐级细分（周按日、月按周、年按月分块），块内归并成「已读《A》《B》」「在看《C》」「追更《D》S1E2」这样的清单，直接回答「这周 / 这个月 / 今年看了什么」；右侧记录按钮**跟随范围切换**（记录今天 / 记录本周 / 记录本月 / 记录今年），把当前范围的动态写成打卡区块写进**当天日记**（日记位置自动跟随核心「日记」插件，未配置时写入 `日记/YYYY-MM-DD.md`；各范围区块互不覆盖，重复点击只更新）
- **趋势**：月度看完趋势图，图例是可点的分类胶囊（全部 / 书籍 / 影视 / 游戏 / 音乐），点一下只看这一类；图下有一行总结（如「本月完成 3 · 比上月 +1」）
- **分类概览**：与趋势图左右并排（面板窄到 900px 以下自动上下堆叠），内部按 Tab 切换 书籍 / 影视 / 游戏 / 音乐，各显示 4 个指标 + Top 3（点条目名可直接打开）；四类颜色与折线、圆点、卡片色条一致

### 数据目录

- 所有数据存放在 vault 内一个目录（默认 `ReelLudic/`，可在 设置 → 基本设置 › 数据与备份 → 媒体库目录 改名）：
```
ReelLudic/
├── catalog.json           # 结构化事实源（条目元数据）
├── catalog-backups.json   # 自动滚动备份（单文件，含最近 5 版）
├── 封面/                  # 本地化封面（封面/{标题}.jpg）
├── 笔记/                  # 详情笔记
│   ├── movie/ teleplay/ animation/ game/ music/
│   └── book/ novel/       # 书籍按子分类分目录（文学 / 网文）
├── 阅读进度/              # 每本书一个 JSON：进度 + 书签 + 高亮
├── 备份/                  # 设置页手动导出的 catalog 快照
└── 报告/                  # 年度总结
```

## 界面外观

打开插件，第一眼看到的是**书架主界面**——一部部「藏品」以封面卡片排满页面。从上到下依次是：

- **顶部页签栏**：计划 / 阅读 / 影视 / 游戏 / 音乐 / 统计 六个页签（图标 + 名称，当前页签有下划线高亮），点击切换收藏空间
- **搜索行**：搜索框按标题实时筛库（Esc 清空）；右侧是「＋ 添加」与库内总数
- **筛选行**：类型胶囊 / 书籍分类胶囊（阅读页签专属：全部 · 文学 · 网文）+ 状态下拉 + 排序下拉 + 题材 + 右侧 ▦ ☷ ▥ 视图切换（音乐多一个 ☰ 分组歌单）
- **书架主体 · 海报墙**（默认视图）：一行行 2:3 封面卡片
  - 卡片上依次是标题、原名 / 年份、创作者、题材行、进度（书籍显示阅读百分比与进度条）
  - 底部一行是状态徽标 + 我的评分 ★
  - **封面右上角**是大众评分小标签（悬停可见数据源）
- **卡片悬停快操作**：hover 卡片浮出——封面右上「⋯ 更多」、封面下方「打开笔记 ↗」、右下圆形 ▶（观看 / 阅读 / 播放 / 启动，随类型变化）；卡片上**右键**出同款菜单
- **勾选条目后**底部浮现批量操作栏（状态 / 评分 / 标签 / 应用 / 删除 / 取消选择）
- **视图切换**：海报墙是封面卡片墙，列表是带排序表头的表格（表头可全选本页），瀑布流是纵向无缝图墙
- **计划页签**：追番表（剧名 / 开播季度 / 进度 SxEy / 更新提示等列的表格）与 排期表（月 / 周日历，左侧「待排期」卡片可直接拖到日期格）
- **统计页签**：三层结构 —— 最上面是核心指标（1 主 4 辅，「生成今年总结 / 往年报告」在主指标卡里）；中间是**动态**，以及**左右并排**的月度趋势与分类概览（窄窗口自动上下堆叠）；添加条目 / 随机推荐 / 想看的清单三个快捷入口在动态的标题行右侧
- 页面右下角还有一个「回到顶部 ↑」悬浮小圆钮

在书架里点 ▶ 或从右键菜单进入，还能看到**编辑器、阅读器与播放器界面**：书籍会打开内置阅读器（TXT / EPUB / PDF 六档主题、目录栏 + 阅读排版），影视本地视频用内置播放器，游戏一键启动 .lnk 快捷方式。

## 设置页

顶部是 **4 个平级入口**（切页时顶栏固定不动，只有下面的内容区滚动）：

- **基本设置**（4 组）：
  - 外观与体验 —— 隐藏插件内滚动条（滚轮仍可滚动）
  - 实验性功能 —— 内置阅读器打开书籍文件（TXT/EPUB/PDF）、内置播放器打开视频文件（默认关闭，关闭时交还系统程序）
  - 数据与备份 —— 媒体库目录（换库入口）、笔记表格、导出备份与备份恢复
  - 封面与清理 —— 下载封面、附件清理
- **数据源配置**：数据源启用（每类型源链的选择与排序）+ 数据源凭据（各数据源凭据填写与「测试连接」）
- **AI集成**：AI服务（翻译 / 总结 / 搜索三套服务商各自可调 + 各自提示词，末尾是**朗读音源**）· API凭据（智谱清言 / DeepSeek / 硅基流动的 Key 与一键「测试连接」）
- **关于**：支持作者入口

## 技术栈

- **语言**：TypeScript（strict）
- **构建**：esbuild + tsc（类型检查）

## 常见问题（FAQ）

### 点 ▶ 打开的是系统程序，不是内置阅读器 / 播放器

内置阅读器与内置播放器都是**默认关闭**的实验性功能（关闭时把关联网页链接与本地文件交还系统程序），开关在 设置 → 基本设置 › 实验性功能：

- 「内置阅读器打开书籍文件」——打开后 TXT / EPUB / PDF 在 Obsidian 标签页里读
- 「内置播放器打开视频文件」——打开后本地视频在插件播放器里播

⚠️ 例外：**笔记里的深链永远走内置**（点笔记里的时间戳链接、阅读器头部链接）——只有内置阅读器 / 播放器能定位到「第几秒」「哪一句」，走系统程序会变成从头开始。

### 搜不到东西，或某一源显示「请求失败」

搜索框下方会列出**每个源的实时状态**——单个源失败不影响其他源，「请求失败」只代表那一个源。按顺序排查：

1. **豆瓣是每类默认的主力源，必须配 Cookie。** 未登录态的请求一律被拒。到 设置 → 数据源配置 › 数据源凭据 → **Douban Cookie**，登录 douban.com 后按 `F12` → Network → 复制任意请求的 `Cookie`（**必须含 `dbcl2` 登录态**）粘贴进去。提示「豆瓣 Cookie 已失效或过期」通常就是这条 Cookie 过期或缺少登录态。
2. **豆瓣密集搜索会被风控。** 短时间内反复搜索容易被判定为爬虫，表现为「请求失败」或空结果。等几分钟再试——插件内部已有请求缓存与串行限流，但仍会触发网站侧的风控。
3. **给每类补一个免 Key 的第二源**，豆瓣不可用时仍有结果：
   - 书籍 → Open Library、Google Books
   - 游戏 → Steam
   - 音乐 → MusicBrainz、iTunes（中文曲库与封面较好）
   - 动画 → AniList（免 Key）
4. **需要凭据的源要先填 Key**：TMDB、OMDb、Bangumi、IGDB（IGDB 需要 Twitch 的 Client ID 与 Client Secret **两个值**）。填完点「测试连接」。
5. **网络不可达**。除豆瓣外的源服务器在境外，网络不通时同样显示「请求失败」。
6. **Google Books 免费额度限流**很常见，填 API Key 可以提升配额。

### 升级后阅读进度、书签、高亮还在吗？（1.1.0 的阅读数据）

在，而且是**自动合并**的——升级到 1.1.0 后首次打开某本书时，插件会把旧版分散的三处数据（进度文件、书签文件、笔记里的「## 高亮」区）**懒迁移**进 `阅读进度/{书名}-阅读-{id}.json`，旧文件保留一个版本再清理，不需要手动操作。

对应的一个行为变化：此后**高亮以阅读档案为准，笔记里的「## 高亮」区变成插件生成的只读镜像**——增删高亮请在阅读器里操作（侧栏「摘抄」页或选中文字后的动作条），手改笔记里那一区不会生效。**摘抄仍照旧写在笔记的「## 摘抄」区**（也可以同样在阅读器侧栏里管理），笔记里的其他内容照样可以随便写。

### 封面不显示 / 一片空白

- 豆瓣图床有防盗链，浏览器里能看、插件里下载会被拒。插件的做法是**选中结果时把封面下载到本地** `ReelLudic/封面/{标题}.jpg`；下载失败会退回远程 URL，此时部分环境下就是空白。
- **手动补封面**：在编辑表单里**把本地图片拖到封面区**，或**右键封面 → 更换封面**。
- **批量修已有条目**：设置 → 基本设置 › 封面与清理 → **下载封面**，把网络封面重新抓成本地文件。
- **换过媒体库目录后**封面路径会失效——封面按库相对路径存放，换库不会自动搬图。
- **清理残留**：设置 → 基本设置 › 封面与清理 → **附件清理**，它会列出没有被任何条目引用的封面文件与条目删除后遗留的阅读存档，逐项勾选后再删除。

### 数据备份、导入导出与迁移

- **自动备份**：每次改动数据前，插件会把上一版 `catalog.json` 存进 `ReelLudic/catalog-backups.json`——**一个文件**内含最近 5 版（内容没变化时不重复存）；写入前还会自检一次「写得进去、也读得回来」，自检不通过就中止本次写入。
- 设置 → 基本设置 › 数据与备份 → **导出备份与备份恢复**：导出生成 `catalog.json` 快照（存 `备份/`）；导入按「标题 + 类型」判重合并，**不会覆盖已有条目**。
- **迁移到新电脑 / 新库**：整个 `ReelLudic/` 目录拷过去即可（含 `catalog.json`、`封面/`、`笔记/`、`阅读进度/`）。搬完检查 设置 → 基本设置 › 数据与备份 → 媒体库目录 是否指向正确位置。
- 详情笔记是普通 Markdown（frontmatter + 属性表 + 章节），可以被任意笔记双链引用，也可以直接手改——**手改的内容在下次打开编辑表单时会被读回**。

### 本地视频黑屏 / 没声音

内置播放器走 Chromium 解码，只稳定支持 **mp4 / webm / mov / ogv**。mkv、avi、flv、wmv 等容器，或 HEVC、AV1 等编码，会黑屏或无声——这类文件会被自动转交给系统播放器。想一律用外部播放器，关掉「内置播放器打开视频文件」即可。

### 追番表检测不到最新集数

更新检测的原理是**抓取条目关联的观看网址页面**、从中提取集数，再与已看进度相减。所以：条目必须关联网页链接；链接页面里要有可识别的集数信息；站点改版或页面结构变化会导致抓取失效。

### 为什么 main.js 有 4 MB

产物是**单文件**，其中内嵌了 PDF 阅读所需的 pdf.js 及其 worker（约 2 MB，占一半上下），换来「三件套直接覆盖安装」的零依赖部署，也避免了 Obsidian 里 PDF worker 取不到的问题。另外插件**没有开启代码压缩**，产物保持可读，便于审计。
