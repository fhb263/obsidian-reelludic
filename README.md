# ReelLudic

> 把媒体信息管理与播放阅读于一体的Obsidian插件。通过元数据自动获取媒体信息，支持关联网页链接和本地文件，内置简易播放器与阅读器，让你轻松管理多媒体笔记。

---

## 这是什么

ReelLudic是一个 Obsidian 插件，把六类收藏（电影 / 电视剧 / 动画 / 书籍 / 游戏 / 音乐）变成库中可管理、可追踪、可双链的结构化资产，并内置简易播放器与阅读器，让收藏真正可看、可读。

<img width="1087" height="968" alt="image" src="https://github.com/user-attachments/assets/4d09f360-9a3a-40cf-aacb-b7739a88eab6" />

**核心理念：一切收藏都以 Markdown + JSON 落盘，原生融入双链笔记生态。**
- `catalog.json` 是**结构化事实源**（目录元数据）
- 每条目自动生成 Markdown **详情笔记**（frontmatter + 属性表 + 简介/评语/链接章节），可手动批注、可被任意笔记双链引用
- 笔记里改的内容（正文章节 / frontmatter / 来源链接）打开编辑表单时**自动回填**，表单保存后笔记再同步生成——双向一致

## 安装

### 方式一：BRAT 安装

1. 在 Obsidian 中安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件
2. 打开 BRAT 设置 → 点击 **Add Beta plugin** → 输入仓库地址：
   ```
   https://github.com/fhb263/obsidian-reelludic/
   ```
3. 安装完成后，在 设置 → 第三方插件 → 启用 **ReelLudic**

### 方式二：手动安装

1. 从本仓库的 [Releases](https://github.com/fhb263/obsidian-reelludic/releases) 下载最新版本的三个文件：
   - `main.js`
   - `styles.css`
   - `manifest.json`
2. 将这三个文件复制到你的 Vault 目录下：
   ```
   <你的Vault>/.obsidian/plugins/obsidian-reelludic/
   ```
3. 重启 Obsidian → 设置 → 第三方插件 → 启用 **ReelLudic**

## 使用方法

### 配置数据源

| 类型       | 默认源链   | 可自选补充源                    |
| -------- | ------ | ------------------------- |
| 图书       | Douban | Open Library、Google Books |
| 游戏       | Douban | Steam、IGDB                |
| 音乐       | Douban | MusicBrainz、iTunes        |
| 电影 / 电视剧 | Douban | TMDB、OMDb                 |
| 动画       | Douban | Bangumi、AniList           |

### 添加条目

1. 点击左侧 Ribbon 的「＋ 添加条目」（或命令面板执行「添加条目」）
2. 在添加弹窗输入标题，自动从配置的数据源搜索——选中结果即回填标题 / 封面 / 年份 / 评分 / 简介等元数据；没有命中也可手动填写
3. 保存后生成两样东西：`catalog.json` 里的结构化条目，以及 `笔记/{类型}/` 下的详情笔记（Markdown，可被任意笔记双链引用）

### 日常管理

- **状态流转**：在卡片 / 列表的操作菜单或编辑表单中切换 想看 → 在看 → 已看 → 存档（文案随类型变化：想读 / 在读、想玩 / 在玩、想听 / 在听）
- **浏览**：右上角切换 海报墙 / 列表 / 瀑布流 三种视图；列表可按列排序，工具栏可筛选状态与类型
- **批量**：勾选多个条目后，底部批量栏可统一改状态、评分、追加标签
- **封面**：右键封面可更换 / 重新下载；封面统一存于 `封面/{标题}.jpg`，设置页可一键迁移或清理未被引用的孤儿封面

### 观看与阅读

- **影视**：点卡片上的 ▶ 播放（单链接直接打开 / 多链接弹窗选择来源）；本地视频在设置开启「内置播放器打开视频文件」后可在 Obsidian 内直接内嵌播放（mp4/webm 等，多集连播）
- **书籍**：关联了本地 TXT / EPUB / PDF 文件的条目，▶ 会打开**内置阅读器**——书签、页内高亮、划词翻译、摘抄写回笔记、连续 / 翻页式切换
- **游戏**：关联 `.lnk` 快捷方式后 ▶ 直接启动；「记录游玩」可录入游玩时长与心得
- **音乐**：关联本地音频后 ▶ 播放；音乐笔记的 `lrc` 模板可与 LyricFlux 侧边栏播放联动

### 追更与排期

- 把连载中的剧集 / 动画标记为「在看」即进入**追番表**：自动检测网站最新集数并提示更新，按活跃度排序
- 在「计划表 → 排期表」为条目设定**计划观看日期**（月历 / 周历视图，拖拽待排卡片到日期格）；到期未开始的条目出现在顶部横幅，点「开始观看」一键转入在看

### 统计与报告

- 打开「统计」页签查看今年 KPI、月度看完趋势与四库分区；点「生成今年总结」一键产出年度报告，之后随时可从「往年报告」回看历年总结

### 数据目录

- 所有数据存放在 vault 内一个目录（默认 `媒体库/`，可在 设置 → 数据管理 → 媒体库目录 修改）：
```
媒体库/
├── catalog.json        # 结构化事实源（条目元数据）
├── 封面/               # 本地化封面（封面/{标题}.jpg）
├── 笔记/               # 详情笔记（按类型分子目录）
├── 备份/               # catalog JSON 备份
└── 报告/               # 年度总结
```

## 界面外观

打开插件，第一眼看到的是**书架主界面**——一部部「藏品」以封面卡片排满页面。从上到下依次是：

- **顶部页签栏**：计划表 / 书籍 / 影视 / 游戏 / 音乐 / 统计 六个页签（图标 + 名称，当前页签有下划线高亮），点击切换收藏空间
- **搜索与筛选行**：搜索框按标题实时筛库；类型筛选 / 状态筛选 / 排序下拉；勾选条目后底部浮现**批量操作栏**
- **书架主体 · 海报墙**（默认视图）：一行行 2:3 封面卡片，卡片上依次是标题、原名 / 年份、创作者、个人评分 ★、大众评分、状态徽标与进度条
- **卡片悬停快操作**：hover 卡片浮出——封面右上「⋯ 更多」，封面下方「打开笔记 ↗」，右下圆形 ▶（观看 / 阅读 / 播放 / 启动，随类型变化）
- **视图切换**：右上角 ▦ ☷ ▥ 在 海报墙 / 列表 / 瀑布流 间切换（音乐页签另有分组歌单视图）；列表是带排序表头的表格，瀑布流是纵向无缝图墙
- **计划表页签**：追番表（剧名 / 开播季度 / 进度 SxEy / 更新提示等列的表格）与 排期表（月历 / 周历，可从侧栏拖拽“待排期”卡片到日期格）
- **统计页签**：最上方是 KPI 数字行，下方为月度趋势与今年动态，再往下是四库分区
- 页面右下角还有一个「回到顶部 ↑」悬浮小圆钮

在书架里点 ▶ 或从右键菜单进入，还能看到**编辑器与播放器界面**：书籍会打开内置阅读器（TXT/EPUB/PDF 沉浸式阅读，顶栏自动隐藏），影视本地视频用内置播放器，游戏一键启动 .lnk 快捷方式。

## 设置页

- **外观**：隐藏插件内滚动条（滚轮仍可滚动）
- **实验性功能**：内置阅读器打开书籍文件（TXT/EPUB/PDF）、内置播放器打开视频文件（默认关闭，关闭时交还系统程序）
- **数据管理**：媒体库目录（换库入口）、导出备份与备份恢复、下载封面、清理孤儿封面
- **服务集成**：① 数据源管理——各数据源凭据填写与「每类型源链」选择；② 阅读器翻译管理——智谱清言 / DeepSeek 的 API Key 与一键「测试连接」
- **关于**：支持作者入口

## 技术栈

- **语言**：TypeScript（strict）
- **构建**：esbuild + tsc（类型检查）
- **UI**：Svelte 4
- **测试**：Vitest（808 单测，52 文件）
- **运行时依赖**：Obsidian API；抓取走 Node https（桌面端）/ requestUrl
