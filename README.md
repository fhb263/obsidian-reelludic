> 把媒体信息管理与播放阅读于一体的Obsidian插件。通过元数据自动获取媒体信息，支持关联网页链接和本地文件，内置简易播放器与阅读器，让你轻松管理多媒体笔记。

---

## 这是什么

ReelLudic是一个 Obsidian 插件，把六类收藏（电影 / 电视剧 / 动画 / 书籍 / 游戏 / 音乐）变成库中可管理、可追踪、可双链的结构化资产，并内置简易播放器与阅读器，让收藏真正可看、可读。

<img width="1087" height="968" alt="image" src="https://github.com/user-attachments/assets/4d09f360-9a3a-40cf-aacb-b7739a88eab6" />

**核心理念：一切收藏都以 Markdown + JSON 落盘，原生融入双链笔记生态。**
- `catalog.json` 是**结构化事实源**（目录元数据）
- 每条目自动生成 Markdown **详情笔记**（frontmatter + 属性表 + 简介/评语/链接章节），可手动批注、可被任意笔记双链引用
- 笔记里改的内容（正文章节 / frontmatter / 来源链接）打开编辑表单时**自动回填**，表单保存后笔记再同步生成——双向一致

## 安装

### 方式一：BRAT 安装

1. 在 Obsidian 中安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件
2. 打开 BRAT 设置 → 点击 **Add Beta plugin** → 输入仓库地址：
   ```
   https://github.com/fhb263/obsidian-reelludic/
   ```
3. 安装完成后，在 设置 → 第三方插件 → 启用 **ReelLudic**

### 方式二：手动安装

1. 从本仓库的 [Releases](https://github.com/fhb263/obsidian-reelludic/releases) 下载最新版本的三个文件：
   - `main.js`
   - `styles.css`
   - `manifest.json`
2. 将这三个文件复制到你的 Vault 目录下：
   ```
   <你的Vault>/.obsidian/plugins/obsidian-reelludic/
   ```
3. 重启 Obsidian → 设置 → 第三方插件 → 启用 **ReelLudic**

## 使用方法

### 配置数据源

| 类型       | 默认源链   | 可自选补充源                    |
| -------- | ------ | ------------------------- |
| 图书       | Douban | Open Library、Google Books |
| 游戏       | Douban | Steam、IGDB                |
| 音乐       | Douban | MusicBrainz、iTunes        |
| 电影 / 电视剧 | Douban | TMDB、OMDb                 |
| 动画       | Douban | Bangumi、AniList           |

### 添加条目

1. 点击左侧 Ribbon 的「＋ 添加条目」（或命令面板执行「添加条目」）
2. 在添加弹窗输入标题，自动从配置的数据源搜索——选中结果即回填标题 / 封面 / 年份 / 评分 / 简介等元数据；没有命中也可手动填写
3. 保存后生成两样东西：`catalog.json` 里的结构化条目，以及 `笔记/` 下按英文类型分目录的详情笔记（如 `笔记/movie/`、`笔记/book/`，Markdown，可被任意笔记双链引用；更新插件后旧笔记自动迁移）

### 日常管理

- **状态流转**：在卡片 / 列表的操作菜单或编辑表单中切换 想看 → 在看 → 已看 → 存档（文案随类型变化：想读 / 在读、想玩 / 在玩、想听 / 在听）
- **浏览**：右上角切换 海报墙 / 列表 / 瀑布流 三种视图；列表可按列排序，工具栏可筛选状态与类型
- **批量**：勾选多个条目后，底部批量栏可统一改状态、评分、追加标签
- **封面**：右键封面可更换 / 重新下载；封面统一存于 `封面/{标题}.jpg`，设置页可一键迁移或清理未被引用的孤儿封面
- **AI 摘要**：编辑表单标题旁 ✨ 让 AI 生成「一句话总结 + 核心看点」（也可完全手填），结果写入笔记对应章节；在笔记里手改也会被表单读回

### 观看与阅读

- **影视**：点卡片上的 ▶ 播放（单链接直接打开 / 多链接弹窗选择来源）；本地视频在设置开启「内置播放器打开视频文件」后可在 Obsidian 内直接内嵌播放（mp4/webm 等，多集连播）
- **书籍**：关联了本地 TXT / EPUB / PDF 文件的条目，▶ 会打开**内置阅读器**——书签、页内高亮、划词翻译、摘抄写回笔记、连续 / 翻页式切换
- **游戏**：关联 `.lnk` 快捷方式后 ▶ 直接启动；「记录游玩」可录入游玩时长与心得
- **音乐**：关联本地音频后 ▶ 播放；音乐笔记的 `lrc` 模板可与 LyricFlux 侧边栏播放联动

### 追更与排期

- 把连载中的剧集 / 动画标记为「在看」即进入**追番表**：自动检测网站最新集数并提示更新，按活跃度排序
- 在「计划表 → 排期表」为条目设定**计划观看日期**（月历 / 周历视图，拖拽待排卡片到日期格）；到期未开始的条目出现在顶部横幅，点「开始观看」一键转入在看

### 统计与报告

- 打开「统计」页签查看今年 KPI、月度看完趋势与四库分区；点「生成今年总结」一键产出年度报告，之后随时可从「往年报告」回看历年总结
- 「动态」面板可切 日 / 周 / 月 / 年：**日**视图逐条列出（几点几分、什么状态、《哪部》）；**周 / 月 / 年**改为周期汇总并逐级细分（周按日、月按周、年按月分块），块内归并成「已读《A》《B》」「在看《C》」「追更《D》S1E2」这样的清单——直接回答「这周 / 这个月 / 今年看了什么」；右侧记录按钮**跟随范围切换**（记录今天 / 记录本周 / 记录本月 / 记录今年），把当前范围的动态写成打卡区块写进**当天日记**（日记位置自动跟随核心「日记」插件，未配置时写入 `日记/YYYY-MM-DD.md`；各范围区块互不覆盖，重复点击只更新）

### 数据目录

- 所有数据存放在 vault 内一个目录（默认 `ReelLudic/`，可在 设置 → 数据管理 → 媒体库目录 改名）：
```
ReelLudic/
├── catalog.json        # 结构化事实源（条目元数据）
├── 封面/               # 本地化封面（封面/{标题}.jpg）
├── 笔记/               # 详情笔记（类型子目录英文：movie/teleplay/animation/book/game/music）
├── 备份/               # catalog JSON 备份
└── 报告/               # 年度总结
```

## 界面外观

打开插件，第一眼看到的是**书架主界面**——一部部「藏品」以封面卡片排满页面。从上到下依次是：

- **顶部页签栏**：计划表 / 书籍 / 影视 / 游戏 / 音乐 / 统计 六个页签（图标 + 名称，当前页签有下划线高亮），点击切换收藏空间
- **搜索与筛选行**：搜索框按标题实时筛库；类型筛选 / 状态筛选 / 排序下拉；勾选条目后底部浮现**批量操作栏**
- **书架主体 · 海报墙**（默认视图）：一行行 2:3 封面卡片，卡片上依次是标题、原名 / 年份、创作者、个人评分 ★、大众评分、状态徽标与进度条
- **卡片悬停快操作**：hover 卡片浮出——封面右上「⋯ 更多」，封面下方「打开笔记 ↗」，右下圆形 ▶（观看 / 阅读 / 播放 / 启动，随类型变化）
- **视图切换**：右上角 ▦ ☷ ▥ 在 海报墙 / 列表 / 瀑布流 间切换（音乐页签另有分组歌单视图）；列表是带排序表头的表格，瀑布流是纵向无缝图墙
- **计划表页签**：追番表（剧名 / 开播季度 / 进度 SxEy / 更新提示等列的表格）与 排期表（月历 / 周历，可从侧栏拖拽“待排期”卡片到日期格）
- **统计页签**：最上方是 KPI 数字行与「动态」时间轴（日/周/月/年 + 一键写日记），下方为**并排**的月度看完趋势与四库分区（1:1，窄窗口自动上下堆叠，四库分区内部列数随容器宽度自适应；添加条目 / 随机推荐 / 想看的清单三个快捷入口在页眉「生成今年总结」左侧）
- 页面右下角还有一个「回到顶部 ↑」悬浮小圆钮

在书架里点 ▶ 或从右键菜单进入，还能看到**编辑器与播放器界面**：书籍会打开内置阅读器（TXT/EPUB/PDF 沉浸式阅读，顶栏自动隐藏），影视本地视频用内置播放器，游戏一键启动 .lnk 快捷方式。

## 设置页

- **外观**：隐藏插件内滚动条（滚轮仍可滚动）
- **实验性功能**：内置阅读器打开书籍文件（TXT/EPUB/PDF）、内置播放器打开视频文件（默认关闭，关闭时交还系统程序）
- **数据管理**：媒体库目录（换库入口）、导出备份与备份恢复、下载封面、清理孤儿封面
- **服务集成**：① 数据源管理——各数据源凭据填写与「每类型源链」选择；② AI 翻译与总结——「翻译服务」「总结服务」两个 AI 服务商各自可调 + 智谱清言 / DeepSeek 的 API Key 与一键「测试连接」
- **关于**：支持 ReelLudic 入口

## 常见问题（FAQ）

### 搜不到东西，或某一源显示「请求失败」

搜索框下方会列出**每个源的实时状态**——单个源失败不影响其他源，「请求失败」只代表那一个源。按顺序排查：

1. **豆瓣是每类默认的主力源，必须配 Cookie。** 未登录态的请求一律被拒。到 设置 → 服务集成 · 数据源管理 → **Douban Cookie**，登录 douban.com 后按 `F12` → Network → 复制任意请求的 `Cookie`（**必须含 `dbcl2` 登录态**）粘贴进去。提示「豆瓣 Cookie 已失效或过期」通常就是这条 Cookie 过期或缺少登录态。
2. **豆瓣密集搜索会被风控。** 短时间内反复搜索容易被判定为爬虫，表现为「请求失败」或空结果。等几分钟再试——插件内部已有请求缓存与串行限流，但仍会触发网站侧的风控。
3. **给每类补一个免 Key 的第二源**，豆瓣不可用时仍有结果：
   - 书籍 → Open Library、Google Books
   - 游戏 → Steam
   - 音乐 → MusicBrainz、iTunes（中文曲库与封面较好）
   - 动画 → AniList（免 Key）
4. **需要凭据的源要先填 Key**：TMDB、OMDb、Bangumi、IGDB（IGDB 需要 Twitch 的 Client ID 与 Client Secret **两个值**）。填完点「测试连接」。
5. **网络不可达**。除豆瓣外的源服务器在境外，网络不通时同样显示「请求失败」。
6. **Google Books 免费额度限流**很常见，填 API Key 可以提升配额。

### 封面不显示 / 一片空白

- 豆瓣图床有防盗链，浏览器里能看、插件里下载会被拒。插件的做法是**选中结果时把封面下载到本地** `ReelLudic/封面/{标题}.jpg`；下载失败会退回远程 URL，此时部分环境下就是空白。
- **手动补封面**：在编辑表单里**把本地图片拖到封面区**，或**右键封面 → 更换封面**。
- **批量修已有条目**：设置 → 数据管理 → **下载封面**，把网络封面重新抓成本地文件。
- **换过媒体库目录后**封面路径会失效——封面按库相对路径存放，换库不会自动搬图。
- **清理残留**：设置 → 数据管理 → **清理孤儿封面**，它会列出没有被任何条目引用的封面文件，逐项勾选后再删除。

### 数据备份、导入导出与迁移

- 设置 → 数据管理 → **导出备份与备份恢复**：导出生成 `catalog.json` 快照；导入按「标题 + 类型」判重合并，**不会覆盖已有条目**。
- 事实源是 `ReelLudic/catalog.json`，`ReelLudic/备份/` 下另有插件自动留的 JSON 备份。
- **迁移到新电脑 / 新库**：整个 `ReelLudic/` 目录拷过去即可（含 `catalog.json`、`封面/`、`笔记/`）。搬完检查 设置 → 数据管理 → 媒体库目录 是否指向正确位置。
- 详情笔记是普通 Markdown（frontmatter + 属性表 + 章节），可以被任意笔记双链引用，也可以直接手改——**手改的内容在下次打开编辑表单时会被读回**。

### 本地视频黑屏 / 没声音

内置播放器走 Chromium 解码，只稳定支持 **mp4 / webm / mov / ogv**。mkv、avi、flv、wmv 等容器，或 HEVC、AV1 等编码，会黑屏或无声——这类文件会被自动转交给系统播放器。想一律用外部播放器，关掉「内置播放器打开视频文件」即可。

### 追番表检测不到最新集数

更新检测的原理是**抓取条目关联的观看网址页面**、从中提取集数，再与已看进度相减。所以：条目必须关联网页链接；链接页面里要有可识别的集数信息；站点改版或页面结构变化会导致抓取失效。

### 为什么 main.js 有 3.6 MB

产物是**单文件**，其中内嵌了 PDF 阅读所需的 pdf.js 及其 worker（约占 61%），换来「三件套直接覆盖安装」的零依赖部署，也避免了 Obsidian 里 PDF worker 取不到的问题。另外插件**没有开启代码压缩**，产物保持可读，便于审计。
