GET https://www.douban.com/j/search?q=test&cat=1002 （带 Chrome UA + Referer） HTTP 403 · 288ms · 21B 响应体：{"r": 1, "code": 403} → 无 Cookie 的机器请求被豆瓣直接拒绝（非 Challenge 页，纯 JSON 403）。
插件内 DoubanClient.request 仅接受 status===200，403 走 throw → doubanFallback 判定 reachable=false → 提示「Douban 兜底不可用（需配置 Cookie）」。
