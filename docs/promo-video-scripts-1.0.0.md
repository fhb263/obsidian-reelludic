# ReelLudic v1.0.0 宣传视频脚本

> 画幅 **16:9 横屏**（B站 / YouTube）｜表达形式 **纯录屏 + 大字幕 + 音效**（无口播）｜目标观众 **影音 / 书 / 游戏 / 音乐收藏党**  
> 配套版本：**60 秒标准版** · **3 分钟深度演示版**

---

## 0. 录制前准备（两份脚本共用）

| 项        | 要求                                                                            |
| -------- | ----------------------------------------------------------------------------- |
| 演示 vault | 建一个干净的临时 vault，预先录入 10~15 个条目，覆盖 6 类型（至少 1 部剧集、1 本书、1 个游戏、1 张专辑）              |
| 本地媒体     | 准备：1 个 mp4 视频（多集可用 2 个文件同作品）、1 本 EPUB、1 本 TXT、1 个 PDF、1 个音频、1 个游戏 `.lnk` 快捷方式 |
| 实验性开关    | 先在 设置 → 实验性功能 打开「内置播放器打开视频文件」与「内置阅读器打开书籍文件」，录正片前保持开启（避免演示中空手）                 |
| 数据源凭据    | 录前把默认源链（豆瓣等）调通一次，避免演示搜索转圈；封面可预先下载好                                            |
| 画面卫生     | 隐藏无关侧边栏；命令面板、弹窗演示前先想好步骤；1080p/60fps、鼠标轨迹干净                                    |
| 隐私       | 临时库、假数据、假评语；不要把真实个人笔记/API Key 录进去                                             |
| 字幕规范     | 字幕单屏 ≤ 12 字，多用短句分行；重点词加粗或变色                                                   |

**诚实性红线**：播放器 / 阅读器为「实验性功能」，字幕如出现须配一句「设置里开启后可用」；不出现「应用商店一键搜到」等文案——本项目通过 BRAT 或手动三件套安装。

# 一、60 秒标准版

节奏：钩子(5s) → 解决/演示(45s) → 收尾 CTA(10s)。共 7 镜，每镜字幕 1~2 屏。

| # | 时间        | 画面（录屏操作）                                                                 | 大字幕                                               | 音效 / 转场                   |
| - | --------- | ------------------------------------------------------------------------ | ------------------------------------------------- | ------------------------- |
| 1 | 0:00–0:05 | 开场黑场淡入：桌面依次弹出收藏夹截图残影（豆瓣想看电影 + 一堆本地文件图标），切 Obsidian 空白的「媒体库」封面墙           | <u>剧集存一堆，书在柜子里，游戏玩到一半——都记在哪了？</u>                 | 电子钟滴答 2 声 → 卡点停；切镜 whoosh |
| 2 | 0:05–0:14 | 点 Ribbon「＋ 添加条目」→ 弹窗输入《星际穿越》→ 数据源命中回填封面 / 评分 / 简介 → 保存后切到书架，新卡片出现        | 搜一次，封面评分全回来 / 电影、剧集、动画、书籍、游戏、音乐，一座库全收下            | 键盘敲击声；成功「叮」               |
| 3 | 0:14–0:26 | 依次点顶部六个页签（书籍→影视→游戏→音乐…）各停 0.5s；右上角切 海报墙/列表/瀑布流；右键菜单里改状态 想看→在看            | 六类独立页签 / 海报墙、列表、瀑布流三种看法 / 想看在看已看，进度随手记            | 页签切换 tick；视图切换丝滑 whoosh   |
| 4 | 0:26–0:36 | 影视页点卡片 ▶ → 本地视频在 Obsidian 内嵌播放 → 点下一集切换；书页点 ▶ → 阅读器翻页、选中文字划词翻译浮层、标黄高亮    | 本地视频直接内嵌播放，多集连播 / 书也能在 Obsidian 里读：高亮、摘抄、AI 划词翻译  | 播放键点按；翻页纸声；翻译「叮」          |
| 5 | 0:36–0:46 | 切「计划表」页签：追番表显示更新提示 → 拖拽待排卡片到月历某天 → 顶部横幅出现到期提醒；再切「统计」点「生成今年总结」            | 追番自动盯更新 / 拖进日历排期，到点提醒你开看 / 一年看完多少，一键出报告           | 日历拖拽音；生成报告「嗖」             |
| 6 | 0:46–0:54 | 打开一条书籍笔记：frontmatter + 笔记正文；切回编辑表单改评语，回笔记看自动同步；打开 媒体库/catalog.json 与 备份/ | 每条都是 Markdown 笔记，能双链引用 / 表单笔记双向同步 / 所有数据落在本地 JSON | 打字音；双链箭头示意声               |
| 7 | 0:54–1:00 | 定格卡片墙全景 → 渐暗出结尾页：ReelLudic · 开源免费 · 支持作者二维码 + 仓库地址                       | 把收藏，变成一座能看能读的媒体库。 / GitHub 搜 obsidian-reelludic   | 音乐收束低音 + 「叮」落版            |

# 三、通用制作建议

- **BGM**：轻电子 / Lo-fi 铺底，60s 版在 0:00、0:26、0:54 三个卡点做重音对齐；3 分钟版按幕切换副歌段。
- **音效包**：点击 tick、翻页纸声、whoosh 转场、成功「叮」、打字声（仅搜标题时）。
- **字幕样式**：大字幕居中偏下，白字 + 深色半透明底，关键词高亮主题色；与 Obsidian 明暗主题都可共存建议用暗色底。
- **封面缩略图**（视频封面建议）：左半书架海报墙实拍截图，右侧大字「六类收藏，一座 Obsidian 媒体库」，副标题「可看 / 可读 / 可双链」。
- **标题候选**：
  - 《把电影/书/游戏/音乐，全部收进 Obsidian 一座库》
  - 《Obsidian 媒体库：自动抓元数据 + 内置播放器阅读器》
  - 《追番、排期、年度报告：你的收藏管家 ReelLudic》
