调试说明（字段取值路径）

Google Books：GET volumes?q=&maxResults=30 → items[].volumeInfo（title/authors/publisher/publishedDate/description/imageLinks.thumbnail/averageRating）。
豆瓣搜索：GET j/search?q=&cat=（1001书/1002影视动画/3114游戏）→ JSON items[]（HTML 片段）→ sid: + <h3> 提取 id/标题/年份/评分/封面。
豆瓣详情：{域}/subject/{id}/ → application/ld+json（导演/编剧/主演/片长/上映年）+ <div id="info">（国家/语言/片长/又名/译者/ISBN/装帧/定价/丛书…）。
常见问题：浏览器直连豆瓣必被 CORS 拦截（插件用 Obsidian requestUrl 可绕过）；无 Cookie 直连返回 JSON 403；游戏详情页是 SPA 无 #info。
