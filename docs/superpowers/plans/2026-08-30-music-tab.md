# 音乐页签（ReelLudic × LyricFlux 联动）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ReelLudic 新增音乐类型/页签，接豆瓣音乐源（cat=1003）搜索回填并生成带 `lrc source` 块的音乐笔记，与 LyricFlux 目录解耦联动。

**Architecture:** 复用现有 Douban 通道（cat/domain 映射 + JSON-LD 解析 + toXxxResult 转换），新增 `music` 类型贯穿数据层（schema 只增不改）、表单（单行本地音频选择）、笔记模板（callout 四行 + lrc 块 + # 个人评语）、视图页签。LyricFlux 不改，用户将 LRC 笔记文件夹指向 ReelLudic 媒体库目录即可播放。

**Tech Stack:** Obsidian API（Electron remote.dialog 音频选择）、Svelte 4、vitest、esbuild。

**设计文档:** `docs/superpowers/specs/2026-08-30-music-tab-design.md`

```ts
    /** 音乐搜索（Douban 单源；结果缓存 30min） */
    async searchMusic(query: string, onProgress?: SearchProgressCb): Promise<MusicSearchResult[]> {
        const q = query.trim();
        if (!q) return [];
        return this.cachedSearch(`music:${q.toLowerCase()}`, () => this.searchMusicFresh(q, onProgress));
    }

    private async searchMusicFresh(query: string, onProgress?: SearchProgressCb): Promise<MusicSearchResult[]> {
        const db = await this.doubanFallback(query, 'music', toMusicResult, createSearchProgress(onProgress));
        const merged = sortByRelevance(mergeBySource([], db.items), query);
        if (merged.length === 0 && !db.reachable) {
            throw this.doubanUnavailableError(db.cookieInvalid);
        }
        return merged;
    }
```

- [ ] **Step 2: main.ts 实现音频选择通道**

`pickLocalVideoPath` 方法后追加：

```ts
    /** 打开系统文件选择器选本地音频（音乐条目）：Electron remote.dialog 返回绝对路径 → 转 vault 相对路径（库外保留绝对路径） */
    async pickLocalAudioPath(): Promise<string | undefined> {
        if (!Platform.isDesktopApp) return undefined;
        try {
            const electron = require('electron') as {
                remote?: { dialog?: { showOpenDialog(opts: unknown): Promise<{ canceled: boolean; filePaths: string[] }> } };
            };
            const dialog = electron.remote?.dialog;
            if (dialog) {
                const res = await dialog.showOpenDialog({
                    filters: [{ name: '音频', extensions: ['mp3', 'flac', 'm4a', 'ogg', 'wav', 'aac'] }],
                    properties: ['openFile'],
                });
                if (!res.canceled && res.filePaths[0]) return this.toVaultRelPath(res.filePaths[0]);
            }
        } catch {
            // remote 不可用：返回 undefined，由表单提示手动输入
        }
        return undefined;
    }

    /** 绝对路径 → vault 相对路径（在 vault 内则去前缀；库外保留原样——LyricFlux 两种都支持） */
    private toVaultRelPath(abs: string): string {
        try {
            const base = this.app.vault.adapter.getFullPath('');
            const norm = abs.replace(/\\/g, '/').replace(/\/+$/, '');
            const b = base.replace(/\\/g, '/').replace(/\/+$/, '');
            if (norm.toLowerCase().startsWith(b.toLowerCase())) {
                return normalizePath(norm.slice(b.length).replace(/^\/+/, ''));
            }
        } catch { /* 忽略 */ }
        return abs;
    }
```
