# 统计页三层重构设计方案（2026-09-22）

> 需求原文（用户给的一句话需求）：
> 统计页重构为三层：核心指标（1 主 4 辅 + 主 CTA）、动态与趋势（左图右动态或上图下动态）、分类概览（Tab 切换，不要四宫格同时铺）；颜色按书影游音统一，图表支持分类筛选，空状态给行动按钮。
> 本文档 = 流程第 1~3 步产出（金标准检索 → 方案对比 → 模块规划），**待用户裁定 D-0~D-10 后才动代码**。

## 二、金标准检索（流程第 1 步）

| 结论 | 出处 | 怎么用 |
|---|---|---|
| **倒金字塔**：顶部高层汇总指标 → 中部趋势 → 底部明细；层次化布局比平铺**减少 40% 洞察时间** | NNGroup / Tufte 系（`uxpilot.ai`、`scalarly.com` 综述） | 印证本次「三层」方向 |
| **眼动实证**：一排 KPI 卡，注意力在**第 1 项最强**、往右递减 ⇒ 5 张等权卡「后两张基本不被看」 | Tableau 眼动研究（同上综述） | 印证「1 主 + 4 辅」而不是 5 等权 |
| **三层指标模型**：Tier1 North Star 3–5 个 / Tier2 支撑指标 / Tier3 下钻 | ClearPoint KPI 实践 | 主指标 + 辅助指标的命名与分工 |
| **数字必须有对照**：没有同比/环比的数字「没有判断价值」 | Girard Media / Scalarly | 支持做同比（D-3） |
| **空状态三要素**：Context（为什么空）+ Direction（下一步，给按钮）+ Preview（骨架） | SaaS dashboard UX（`designpixil.com`） | 动态区/概览空态改造（D-7） |
| **渐进披露 & 分块**：Tabs / 展开区 / 下钻，让认知负荷显著下降 | ThoughtSpot「Groups & Tabs」、UX patterns | 四宫格 → Tab（D-4） |
| **一组最多 6 个可视化**；每个 Tab 只回答一个高层问题 | ThoughtSpot | 概览 Tab 内只放「4 指标 + Top3」，不塞更多 |
| **视觉编码必须一致**：同一个色在整站是同一个含义 | Scalarly / ClearPoint | 图表色收敛到 `TYPE_COLORS`（D-5） |
| 同类产品（Letterboxd Year in Review / Goodreads）：总览大数 → 分项 → Top 榜 | 官方文档 | 结构顺序参照 |

## 三、技术方案对比（流程第 2 步）

| 方案 | 做法 | 优点 | 风险 |
|---|---|---|---|
| **A 最小改动** | 只在 `StatsBoard.svelte` 内重排 DOM + 改样式；同比/环比在组件里用 `$:` 现算 | 改动面最小、最快 | 组件继续膨胀（≈1000 行）；新增的同比/概览聚合**不可单测**，与项目 TDD 约定冲突 |
| **B 纯逻辑下沉（推荐）** | 新增 `pure/statOverview.ts`（同比/环比、分类概览聚合、趋势序列打包）→ 组件只做渲染；必要时把「概览 Tab 区块」抽成子组件 | 契合项目「纯逻辑必须下沉 + 同位测试」；新增口径有单测兜底；组件瘦身 | 多一个模块要多写一份测试（成本可接受） |
| **C 全组件化** | 拆 `StatKpi.svelte` / `StatTrend.svelte` / `StatCategory.svelte`，`StatsBoard` 只剩编排 | 单文件最小、可独立演进 | 多一层 props 链（与本仓「大而少」的组件风格相反）；scoped 样式跨组件更难断言 |

**推荐 B**（含把概览 Tab 区块抽成子组件）：既守住 TDD 约定，又不引入过深的组件层级。

## 五、逐块改法

### 1. 顶部：5 等权 → 1 主 + 4 辅
- 主卡：「今年看完」大号数字 + **同比**（`↑ 比去年 +2`，去年为 0 时显示「去年 —」不画箭头）+ 主 CTA（生成年终总结 / 往年报告）。
- 辅卡：本月看完 / 在追在读 / 本月计划 / 库内总数，小一档字号。
- 主卡是否随概览 Tab 联动 → **D-2**。

### 2. 动态区：空态给按钮 + 保留最近动态
- 空态 = 说明 + 行动按钮（添加条目 / 随机推荐 / 想看的清单）→ **D-7**。
- 非空时保持现有「日逐条 / 周月季分组」两种形态，不动。

### 3. 趋势图：图例 → 可点筛选 chips
- chips：全部 / 书籍 / 影视 / 游戏 / 音乐；**0 数据分类不渲染 chip**（与题材池「空值不进池」同口径）。
- 单选还是多选 → **D-6**。
- 图下加一句「本月 3 · 比上月 +1」结论行。
- 颜色收敛 → **D-5**；网格线保留几条 → **D-5b**。

### 4. 概览：四宫格 → Tab
- Tab = 书籍 / 影视 / 游戏 / 音乐（影视内部保留「电影 N · 剧集 N · 动画 N」一行）。粒度是否拆成 6 类 → **D-4**。
- Tab 内：4 个指标 + Top3（可点）+ 可选「查看全部 →」→ **D-10**。

### 5. 颜色系统
- 统一走 `TYPE_COLORS`；影视取 movie 蓝；统计页内不再出现硬编码色值 → **D-5**。
