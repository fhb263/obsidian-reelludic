# 内置播放器：留白 / 中央按钮 / 进度条 / 自动隐藏 / 后台省电 — 设计文档（2026-09-18）

> 用户两轮指示。**第一轮**：① 留白用白色高斯模糊填充 ② 去掉画面正中那个「硕大的、老旧的原生播放按钮」，改点击画面任意位置切播放/暂停 + 悬停显示极简半透明微动效按钮 ③ 顶栏「外部打开」换极简图标 ④ 进度条加粗 + 悬浮显示 `00:03 / 00:52` ⑤ 控制栏「鼠标移入显示、移出 3 秒自动隐藏」。
> **第二轮（上手后反馈，本版口径）**：「黑边不要高斯模糊了，用 55% 白罩，不要悬停出按钮暂停出按钮就行了，也不要常驻淡显了正常点，还有性能优化：当视频在后台或不可见时，自动停止渲染，释放 GPU 和内存」。
> 状态：**已实施并验证完毕**（提交与 push 归用户）。

## 0. 需求核查（三处与现状不符，先澄清再做）

| 用户的说法 | 实际情况 |
|---|---|
| 「去掉中间那个**原生**播放按钮」 | **不是原生** —— `videoEl.controls = false` 早在 2026-09-15 就定下自绘控件；那个 64px 深色圆钮是插件自绘的 `.rl-vp-bigplay`。要换掉的是它。 |
| 「改为点击画面任意位置切换播放/暂停」（当作新需求） | **已经生效** —— `videoEl` 铺满整个 stage（`width/height:100%`），点留白区也算命中，`onStageClick` 带 220ms 双击窗口（双击 = 全屏）。本轮只需保留，不动这条主交互。 |
| 「用 55% 白罩」 | 白罩是**半透明的一层**：盖在黑底上会得到**中灰**（rgb≈140），不是白。第二轮确认了这条 → 最终取**白色实底**。 |

## 2. 最终方案

### 2.1 留白 = 舞台白底（D-5）

```
.rl-vp-stage                        （flex 居中；position: relative）
├─ video                            （object-fit: contain；background: transparent）
└─ .rl-vp-centerplay                （56px 圆；pointer-events: none；仅暂停时显示）
```

- 舞台 `background: #fff`，主 video `background: transparent` —— **两处配对**；video 若保留 `#000`，留白还是黑的。
- 已撤销首版的镜像 `<video>` + `filter: blur(38px)` + 白罩整套（含 `.rl-vp-blur*` 四规则、`syncBlurPlayback()`、纯函数 `blurNeedsSync` 与其单测），各自带反向守卫。撤销原因：**同一文件被解码两次**（1080p 下开销可观）+ 观感。
- 顺带留一条通用坑：**CSS 的 `backdrop-filter` 糊不到自己的子元素**（只糊「身后同一层叠上下文」的内容）—— 做毛玻璃底前先问「被糊的东西在不在这一层」。

### 2.2 中央按钮 = 仅暂停时显示（D-3 二次裁定）

撤掉悬停浮出规则、撤掉暂停淡显 `.45`、撤掉呼吸细环 `@keyframes rl-vp-ctr-ring`。

| 状态 | 规则 |
|---|---|
| 默认 | `.rl-vp-centerplay { opacity: 0 }` |
| 暂停 | `.rl-vp-paused .rl-vp-centerplay { opacity: 1 }`（满不透明） |
| 播放中 | 不显示（悬停也不出） |

🔴 **`pointer-events: none`**：点击一律落到主 video —— 与「点画面任意位置切播放/暂停」**共用同一条通道**；若让它自己接 `click`，会与冒泡到 video 的那次切换**互相抵消**（等于点了没反应）。JS 侧只落状态类 + 切图标，不再有第二处显隐真源。

### 2.3 顶栏「外部打开」图标化（D-2）

文字按钮 → `rl-vp-iconbtn` + `external-link`，原说明移入 `data-tip`，位置仍在顶栏最右。

### 2.4 进度条与悬停预览（④）

底 4 → **6px**、悬停 6 → **9px**、拖动柄 12 → **14px**；命中区同步加到 14px（否则「条粗了但边缘点不到」）。悬停预览由「只有落点」改纯函数 `hoverTipText(落点, 总长)` → `0:03 / 0:52`。

### 2.5 自动隐藏（⑤ + D-4）

`IDLE_HIDE_MS` 2600 → **3000**，并补 `mouseleave` —— 鼠标移出即从这一刻重新起计时（旧实现只在移动时重置）。**暂停时不隐藏**的判据（`!paused && !dragging`）保留。

### 2.6 后台省电（D-6 / D-7）

**三路信号合判，任一为否即视为不可见**（单一信号都有盲区，合判才不漏）：

| 信号 | 覆盖 |
|---|---|
| `document.visibilityState === 'hidden'` | 窗口最小化 / 切到别的应用 |
| `containerEl.isShown()`（Obsidian API） | 页签被切走 / 面板收起（旧版本缺失时按「显示着」处理） |
| 舞台的 `IntersectionObserver` | 兜住布局裁切等意外情形 |

**状态机**

```
不可见 → vis.resume = 本在播?  → pause()（解码器停下，释放 GPU）
                              → hideNextPanel()（别在看不见时偷偷切下一集）
                              → 起 HIDDEN_RELEASE_MS（5 分钟）计时
           └─ 计时到点 → deepRelease()：记 {pos, playing} + savePosition(true) + 清源（放掉解码缓冲与内存）

恢复可见 → deep 有值 → deepRestore()：重挂源 → pendingResume 跳回原位 → 重新点亮字幕轨道（load() 会把它打回 disabled）
           └─ 否则  → 按需 play() 续播（被自动播放策略拦时提示「已恢复到前台，点画面继续播放」）
```

**边界处理**（都是会踩的）：首次判定只记账（`primed`：刚挂载没测量出尺寸时别误暂停）；只在**边沿**动作（`layout-change` 很密集）；换片/关闭 `cancelDeepRelease()`（别拿旧位置跳新片）；关闭摘掉 `visibilitychange` 监听与观察器。

## 5. 人工验收清单（测试库 `Ctrl+P → Reload app without restarting` 后）

1. 播一个与容器比例不同的片子 → 上下留白是**白色**。
2. 播放中：画面正中**没有**按钮（鼠标悬停也不出）。
3. 暂停：正中显示一个正常的 ▶（满不透明，不再半透明淡显）。
4. 点画面任意位置 → 播放/暂停；双击 → 全屏。
5. 顶栏最右：只有一个 `↗` 图标。
6. 进度条明显变粗；悬停气泡显示 `0:03 / 0:52`。
7. **切到别的页签** → 播放停止（任务管理器里 GPU 占用应下降）；切回来 → **自动续播**。
8. 切走超过 5 分钟再回来 → 重新加载并**跳回原来的播放位置**（首帧会缓冲一下）。

## 6. 已知取舍

- **不可见即暂停**意味着切走期间没有声音（这是「真释放解码器」的代价）。若将来想要「只听声音」，需要改 D-6 并接受解码器继续跑。
- **彻底释放**后回来会重新加载并缓冲一下（换来的是内存/缓冲真的放掉）。
- 白色留白在深色主题下反差较大 —— 这是用户明确选定的观感；若要跟随主题，改成 `--background-primary` 即可（当前是固定 `#fff`）。
