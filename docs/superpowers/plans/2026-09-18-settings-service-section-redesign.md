## 一、现状诊断（以截图为准，逐条落到代码）

截图实测层级（缩进 / 字号 / 字重三者互不成体系）：

```
服务集成            ← 原生 setHeading()，16px / 600，缩进最大
  ① 数据源管理       ← .rl-svc-section-title，**13px / 600**，缩进最小
  数据源启用      ▸  ← .rl-svc-group-title，**16px / 600**，缩进居中
  数据源凭据      ▸
  ② AI集成          ← 13px / 600
  AI服务          ▸  ← 16px / 600
  API凭据         ▸
```

### 缺陷 1：层级倒挂（**主因**）

| 元素 | 字号 | 字重 | 观感层级 |
|---|---|---|---|
| `服务集成`（原生 heading） | `--font-ui-medium` = 16px | 600 | 一级 |
| `① 数据源管理`（`.rl-svc-section-title`） | `--font-ui-small` = **13px** | 600 | **三级（比子分组还弱）** |
| 四个子分组（`.rl-svc-group-title`） | **未设 font-size → 继承 16px** | 600 | 一级（与「服务集成」同款） |

→ 上级（①②）比下级（子分组）**更小**；而下级又和大标题**一样大**。三层里两层撞款、一层倒挂。

### 缺陷 2：缩进呈锯齿

`服务集成`（原生 heading 有内距）→ `①`（自定义 div，**无 padding，贴容器左缘**）→ 子分组（`padding: 6px 8px`）三者各退一档，形成「进—退—进」的锯齿，不表达任何层级。

### 缺陷 3：`▸` 箭头孤悬

`.rl-svc-group-caret { margin-left: auto }` 把它顶到**容器最右缘**，与标题文字之间隔 400+ px。在宽设置页里读起来不像「这一行的展开按钮」，像另一个控件；hover 时整行铺出一条超长色带。

### 缺陷 4（观感层）：默认全收起 → 页面从上到下只有 6 行标题，信息量为零

## 二、金标准检索结论

检索了 Obsidian 官方插件规范与社区折叠实现：

1. **Obsidian 官方 Plugin guidelines（明确条文）**：
   - 🔴 **「Use `setHeading` instead of a `<h2>`」** —— 原文：「Using the heading elements from HTML will result in **inconsistent styling between different plugins**」。→ 我们的 `.rl-svc-section-title` 是同类问题：**自造标题元素必然与设置页其余部分不同款**，这正是「① 看着突兀」的根因。
   - 「Avoid adding a top-level heading in the settings tab, such as "General", "Settings", or the name of your plugin」；「Section headings don't have "settings" in the heading text」、「Use Sentence case」。
2. **Obsidian 原生设置页只有两层**：`setHeading()`（h2 级）＋ `Setting` 行（左侧名称/说明、右侧控件）。**原生没有第三层**。我们硬造第三层（①②），必然与原生语言打架。
3. **社区折叠分组的做法**（Fevol 的 foldable settings gist、Admonition 插件）：`<details>/<summary>` + 整块折叠，用于**大块**（如「全部高级设置」）；标题本身仍是原生观感，不另造一套标题层级。

**结论**：正确方向是**把层级收敛回 Obsidian 的语言** —— 要么让 ①② 变成真正的 `setHeading()`，要么干脆取消这一层。

## 三、三个方案

### 方案 A · 原生派（贴齐 Obsidian，改动最小）

```
① 数据源管理                      ① 数据源管理          ← 原生 setHeading（与「外观」「数据管理」同款）
──────────────────────            ──────────────────────
数据源启用          ▸             数据源启用          ▸   ← 原生 setting 行观感：整行 + hover 出底
数据源凭据          ▸             数据源凭据          ▸
                                  ① 数据源管理 …内容…
② AI集成                          ② AI集成
AI服务              ▸             AI服务              ▸
API凭据             ▸             API凭据             ▸
```

- ①② 改 **`new Setting(parent).setHeading().setName(...)`**（删 `.rl-svc-section-title` 与 `createSectionTitle`）→ 与整页其余标题自动同款、随主题变。
- 子分组标题行改为**原生 setting-item 观感**：左侧标题（`--font-ui-medium` / 500）、右侧 caret 占「控件位」，**整行 hover 出 `--background-modifier-hover`**（与原生 setting 行一致 —— 于是箭头不再孤悬，它有整行的底托着）。
- 缩进：全部 0（不额外加 padding），内容 `+14px`。
- 改动量：小（Settings.ts 两处、styles.css 一段）。

### 方案 B · 紧凑派（箭头贴文字）★ 推荐

```
① 数据源管理                      ① 数据源管理          ← 原生 setHeading
──────────────────────            ──────────────────────
数据源启用          ▸             数据源启用 ▸          ← 箭头紧贴标题（去掉 margin-left:auto）
数据源凭据          ▸             数据源凭据 ▸
                                  ① 数据源管理 …内容…
② AI集成                          ② AI集成
AI服务              ▸             AI服务 ▸
API凭据             ▸             API凭据 ▸
```

- 在 A 的基础上，**箭头不再顶到最右**，紧跟在标题文字之后（`gap: 6px`，无 `margin-left:auto`）→ 视线不需要横跨整页找展开按钮；hover 时「标题 + 箭头」是一小段可点区域，色带不再横跨整行。
- 缩进：标题与内容同一缩进（`+0` / 内容 `+14`），彻底消灭锯齿。
- 代价：行内不再有「右侧控件位」的原生语义（但那本来也是内容折叠、不是开关）。
- 改动量：小（同 A，多一条 CSS 差异）。

### 方案 C · 卡片派（分组边界最清楚，改动最大）

```
┌────────────────────────────┐
│ ① 数据源管理                │  ← 原生 setHeading（卡片外）
│ ┌────────────────────────┐ │
│ │ 数据源启用           ▸ │ │  ← 卡片头（浅底 + 圆角）
│ │  ☐ 书籍 ☐ 影视 …      │ │  ← 卡片体（展开时）
│ ├────────────────────────┤ │
│ │ 数据源凭据           ▸ │ │
│ └────────────────────────┘ │
└────────────────────────────┘
```

- 四个子分组各包一张 `--background-secondary` + 1px 边框的圆角卡片；卡头 = 标题 + 右侧 caret，卡体 = 内容。
- 分组边界最清楚，也最能装「多个开关」；但**与 Obsidian 原生设置页语言距离最远**（原生设置页没有任何卡片），且需新增约 10 条 CSS、hover 与主题适配面变大。
- 改动量：中（首版还可能要调深浅主题对比度）。

| | A 原生派 | **B 紧凑派** | C 卡片派 |
|---|---|---|---|
| 修层级倒挂 | ✓ | ✓ | ✓ |
| 修缩进锯齿 | ✓ | ✓ | ✓ |
| 修箭头孤悬 | 部分（靠整行底托） | ✓ | ✓ |
| 与原生语言一致 | 最高 | 高 | 低 |
| 改动量 | 小 | 小 | 中 |
| 风险 | 箭头仍离文字远 | 少 | 主题对比度需复调 |
