# 内置播放器 B 站式布局改造 — 设计方案

日期：2026-09-18
状态：待裁定（决策点 D-1 ~ D-8 未定，未动代码）
来源：用户提供 B 站网页播放器截图，要求「把部分布局搬到插件内置播放器」

---

## 一、来源元素清点（截图里有什么）

按从上到下、从左到右拆：

| 区域 | 元素 | 说明 |
|---|---|---|
| 控制条左 | 上一集 / 播放暂停 / 下一集 | 三个纯图标，无底无边框 |
| 控制条中 | 进度条 + `00:02 / 15:15` | 时间紧贴进度条右侧 |
| 控制条中 | 弹幕开关 + 「已关闭弹幕」状态文字 | 灰字提示当前状态 |
| 控制条中 | 弹幕输入框 + 发送 | 底部中央 |
| 控制条右 | `1080P 高清`（画质） | 文字按钮 |
| 控制条右 | `选集` / `倍速` / `字幕` | 文字或图标按钮 |
| 控制条右 | 音量图标 / 设置齿轮 / 网页全屏 / 全屏 | 图标按钮 |
| 浮层 | 选集列表 | 从「选集」向上浮出，当前集高亮 |
| 视频右侧 | 点赞 / 投币 / 收藏 / 分享 竖排 | 视频外缘 |
| 顶部 | 无任何 UI | 标题在播放器之外的页面里 |

关键结构特征只有三条：

1. **控制条单行**。播放控件在左、进度条居中吃掉全部剩余宽度、功能入口在右，全部同一行。
2. **按钮无常态容器**。图标纯白、无底无边框，仅 hover 时出现一层淡底。
3. **低频功能收进浮层**。选集、倍速、画质、设置都是「点开一个浮层选」，不常驻控件。

## 二、现有实现盘点

`src/views/VideoPlayerView.ts`（1120 行）+ `styles.css` 播放器区块（约 2830-2700 行段）。

现有 DOM：

```
.rl-vp-root
├─ .rl-vp-bar         顶栏浮层：片名 + [‹ 上一集][下一集 ›][字幕⧉][↗]
├─ .rl-vp-stage       白底舞台 + video + .rl-vp-centerplay
├─ .rl-vp-controls    底部控制条浮层
│   ├─ .rl-vp-progress  ← 独占一整行：缓冲段 / 已播段 / 拖动柄 / 悬停预览气泡
│   └─ .rl-vp-row       [▶][12:34 / 45:00] …spacer… [🔊][━━━━音量条][1×][PiP][⛶]
├─ .rl-vp-toast
└─ .rl-vp-next        连播倒计时面板（right:18px / bottom:76px）
```

必须保留的既有裁定（不得违反）：

- 退出只经关闭所在标签页 —— 不加 ✕、点留白不关闭、Esc 不退出。
- 顶栏标题居中、标题前无图标。
- 播放中 3s 自动淡出控制条与顶栏；暂停时不隐藏。
- 留白 = 舞台白底 + 主 video `background: transparent`（配对出现）。
- 控件样式一律以 `.rl-vp-root` 打头（特异性 0,2,0），否则图标会被压成 0 宽。
- `.hidden` 类必须自带 `display:none` 规则（本插件无全局 `.hidden`）。

## 三、可搬 / 不可搬清单

### 可搬（6 项）

| 编号 | 内容 | 落地位置 |
|---|---|---|
| M1 | 控制条单行化（左控件 / 中进度 / 右功能三段） | `.rl-vp-controls` |
| M2 | 按钮去常态容器（常态透明、hover 出淡底） | `.rl-vp-root .rl-vp-btn` |
| M3 | 选集浮层（当前集高亮） | 新增 `.rl-vp-menu` |
| M4 | 倍速改「点开列表选」（替代点击循环 + Shift 反向） | 同上 |
| M5 | 设置齿轮收纳低频项（画中画、外部打开） | 同上 |
| M6 | 进度条细线化 + 时间移到进度条右侧 | `.rl-vp-progress` / 单行中段 |

附带可参考的小细节：状态文字提示（B 站「已关闭弹幕」→ 我们可对应「无字幕 / 已挂载某字幕」）、hover 展开音量滑条（列为 D-7）。

### 不可搬（5 项，附理由）

| 内容 | 不搬的理由 |
|---|---|
| 弹幕开关、弹幕输入框 + 发送 | 插件无弹幕系统，无数据源 |
| 画质切换 `1080P 高清` | 本地单文件，不存在多码率 |
| 网页全屏 | 与「全屏」语义重复，Obsidian 里没有「网页」这一层 |
| 右侧竖排点赞 / 投币 / 收藏 / 分享 | 媒体库无社区互动对象 |
| 返回按钮 / 锁屏 / 截图 | 与「退出只经关闭标签页」口径冲突；Obsidian 已有系统级截图 |

## 五、三个方案

| | 方案 A · 轻搬 | 方案 B · 中搬（推荐） | 方案 C · 重搬 |
|---|---|---|---|
| 内容 | M1 + M2 + M6 | A + M3 + M4 + M5，顶栏瘦身为纯标题 | B + 音量悬停展开 + 顶栏彻底撤销 |
| 顶栏 | 不动（上一集/下一集/字幕仍在顶栏） | 只留标题；上/下一集下移到控制条左组，字幕下移到右组，↗ 进齿轮 | 撤销顶栏，标题置于控制条左端 |
| 新增功能入口 | 无 | 选集浮层、倍速面板、齿轮菜单 | 同 B，另加音量 hover 展开 |
| 新增纯逻辑 | 无 | `pure/playerMenu.ts` + 单测 | 同 B，另加音量展开状态机 |
| 改动文件 | VideoPlayerView + styles.css | 上述 + pure 新模块 + tests + 文档 | 上述 + 更多回归面 |
| 风险 | 低 | 中（浮层开合 / Esc / 定位） | 高（顶栏撤销后信息缺失；hover 展开在窄窗口易误触） |
| 观感接近度 | 60% | 90% | 95% |

推荐 B。理由：三条 B 站特征（单行、无底按钮、收录浮层）都拿到了；顶栏撤销（方案 C）会让「正在看哪部片、第几集」失去常驻显示，属于为观感牺牲信息，不划算；音量 hover 展开是鼠标悬停类交互，在 Obsidian 的可变窗口宽度下可发现性与稳定性都差，且现状常驻滑条在桌面端更好用。

## 六、方案 B 模块规划

### 1. 新增 `src/pure/playerMenu.ts`（纯逻辑，TDD）

```ts
buildSpeedOptions(cur: number): { value: number; label: string; active: boolean }[]
buildEpisodeOptions(items: { index: number; title?: string }[], cur: number, single: boolean)
  → { index: number; label: string; active: boolean }[]        // label 用「第 N 集」+ 可选集标题
nextMenuState(cur: MenuKind | null, clicked: MenuKind): MenuKind | null   // 开合互斥
menuAnchor(rect, menuSize, viewport): { left, top }            // 定位；复用纯函数便于单测
```

新增 `tests/playerMenu.test.ts`，覆盖：倍速档位与 active 标记、选集列表标签与 active、同一入口二次点击关合、异入口切换、定位在视口边缘的夹取。

### 2. `src/views/VideoPlayerView.ts` 改造

- `buildControls`：由「两行」改为「单行三组」。左组 = 上/下一集 + 播放暂停；中段 = 进度条 + 时间；右组 = 选集 + 倍速 + 字幕 + 音量 + 齿轮 + 全屏。
- 新增浮层 `.rl-vp-menu`（选集 / 倍速 / 设置三种内容共用一个容器，靠状态类切内容）。
- 外点关闭：document 捕获阶段 `pointerdown` 判断是否落在浮层与触发按钮内，否则关闭。
- Esc：现有处理器是「全屏中返回 true，否则 false 吞键」。新增一级优先级 —— **浮层开着时先关浮层**，再走全屏判断。这是对既有裁定（Esc 不退出播放器）的补充，不冲突。
- 与连播面板互斥：两者占同一区域，开一个时关另一个。
- 选集选中后浮层保持打开并把高亮滚到当前集，还是直接关闭？（建议直接关闭 + 切集，列为 D-8）

### 3. `styles.css`

- 重写 `.rl-vp-controls` 为单行（`flex-direction: row`，`align-items: center`）。
- 新增幽灵按钮变体 `.rl-vp-root .rl-vp-btn.rl-vp-ghost { background: transparent; border-color: transparent; }` + hover 淡底。**必须写在 `.rl-vp-root` 作用域内**，否则被 Obsidian 核心 `button:not(.clickable-icon)` 压过。
- 新增 `.rl-vp-menu` 系列 + `.hidden` 自带规则。
- 进度条细线化（底/已播 6px → 3px，悬停 9px → 6px，拖动柄同步缩小）；命中区高度保持不变。
- 连播面板 `bottom: 76px` → 按单行控制条新高度下调。

### 4. 文档与断言

- `docs/…/UI-GUIDE.md` §9 播放器一节同步。
- `Project-Rule/` 与 `CHANGELOG.md` 记一笔。
- `assert-symbols.cjs` 增加锚点：单行容器类、幽灵按钮类、浮层类、`pure/playerMenu` 导出符号。

### 5. 验证

构建（告警数对齐基线）→ 定向单测 `npx vitest run tests/playerMenu.test.ts`（跨模块再跑全量）→ 产物断言 → 三产物 md5 一致 → 部署测试库实机验证。
