# 阅读器翻页模式（D4b：TXT/EPUB 真分页渲染）设计

> 日期：2026-09-04 | 状态：已实现（TXT + EPUB 双面板，784 全绿；默认连续、下拉可切翻页） | 范围：ReelLudic 阅读器 TXT + EPUB 由连续滚动扩展出「翻页模式」
> 前置：批1（仿 Readest UI）+ 批1.5（软件式沉浸）+ 翻译批 + 高亮批已完成；批1 spec D4 明说「真翻页式渲染不纳入本批（D4a），列为后续预研项」→ 本批（D4b）填充。
> 目标：阅读器支持「连续滚动（默认）/ 翻页」两种可切换阅读模式，翻页用 CSS 列式分页 + 横向翻页，进度沿用「章+百分比」语义不重写。

## 决策（用户已确认）

| 决策点 | 结论 |
|---|---|
| 渲染机制 | **CSS 列式分页**：正文容器一次排满为 N 个「屏宽列」，每列 = 一页（列高 = 阅读区可视高）；翻页平移列容器（快、无缝、无页高闪烁） |
| 与连续关系 | **两模式可切换**：连续（现有滚动）与翻页（列式）并存；阅读器下拉/设置选模式；**默认连续**（升级不惊动现有体验） |
| 进度语义 | **沿用「章 + 百分比」**：翻页页码换算章内百分比，进度仍存 `scrollRatio` 语义；**不新增页进度字段**（字号/窗口变则页边界漂移，但百分比不变、不丢位置） |
| 翻页手势 | **全手势**：footer ‹ › 上一页/下一页 + 滚轮/触控板横向切页 + 键盘左右箭头 + 点屏幕两侧区域 |
| EPUB 版式 | **单列翻页**：翻页模式下 EPUB 由现有双栏（columns:2）改单列，一屏一页，与 TXT 页码口径统一 |

## 架构洞察：内容流 → 统一前进比例

连续与翻页在 DOM 上都把「当前章内容」铺在阅读容器里，区别只在如何**定位到当前位置**，二者可统一表达为**章内内容的前进比例 ratio**：

- 连续模式：`ratio = scrollTop / (scrollHeight − 视口高)`（现有纵向滚动）
- 翻页模式：`ratio = 页index / (总列数 − 1)`（列高 = 阅读区可视高，总列数 ≈ 纵向总长/视口高的同义）

两条路径只在一个换算点产出同一 `scrollRatio` → **进度持久化、跨章百分比、字号/窗口重排、位置记忆全部复用现有逻辑，不重写**。

佐证：EPUB 正文当前已在用 CSS `columns:2`（applyLayout 双栏）——证明 columns 在 iframe 内可行；翻页即把其做成「单列 + 横向平移翻页」。

## 数据模型 / Schema

- 新增阅读设置字段 `readerScrollMode?: 'continuous' | 'paged'`（缺省/旧数据 = 'continuous'；append-only，零迁移）。落点：`ReaderSettings`（与 readerFontSize/readerLineHeight 同区）。
- 阅读器 options 增 `scrollMode: 'continuous' | 'paged'` + `onScrollModeChange?(m)`（写回 settings，跨面板会话共享默认可沿用现有 readerFontSize 会话变量先例）。

## 交互

- 阅读器右上下拉「滚动模式」：现「连续滚动 = 当前可用 / 翻页式 = 后续版本占位移灰」→ 改为两标签可点，当前项高亮；点击切换并即时重建当前章视图。
- footer：连续模式 ‹ › = 上一章/下一章（现状不变）；翻页模式 ‹ › = 上一页/下一页（到章头再上一 = 翻上一章、到章尾再下一 = 翻下一章）；右侧百分比在翻页模式显示「页 N / 总 N · 章内 X%」。
- 翻页手势（仅翻页模式）：点正文左右两侧 1/4 区域翻页、滚轮/触控板横向、左右方向键、‹ ›。
- 定位（高亮/摘抄/书签跳转）：翻页模式下按目标 scrollRatio 换算到目标页并平移过去；连续模式维持现状 scrollIntoView。

## 架构 / 改动拆分

- `src/pure/paged.ts`（纯逻辑 TDD）：页码 ↔ scrollRatio 换算（`pageToRatio(index,total)` / `ratioToPage(ratio,total)` / 约束钳制）；`totalColumns` 由容器尺寸与内容长导出非纯，放 DOM 层。
- `Settings.ts`：`readerScrollMode` 字段 + 默认 'continuous'。
- 下拉/设置 UI：滚动模式两项可点（continuous/paged），当前高亮；写回 settings。
- TXT（`TxtReaderModal`）：新增翻页渲染路径——正文容器在翻页模式下切 CSS columns（单列宽 = 可视宽）隐藏纵向滚动、`transform: translateX(-i*列宽)` 平移；连续路径与现有方法不动；所有 scrollRatio 读写在翻页模式经 `paged.ts` 换算；重排/字号变 → 重算总列 + 按原 ratio 归位；mark 高亮在 columns 内正常（段落仍在 p）。
- EPUB（`EpubReaderModal`）：翻页模式在 iframe 内同样做单列 columns + 横向平移（复用现有 columns 布局逻辑改造）；事件/滚轮监听适配翻页。
- 字号/行距 A± 在翻页模式同样触发列数重算 + 按 ratio 归位。
- 触底自动翻章 / 翻页到章尾再翻 → 翻下一章（对称于 navNext 现状）。

## styles.css 新增

- `.rl-reader-body.rl-paged` 之类模式类：翻页时正文容器禁纵向滚动、启用列式/平移。

## 测试策略

- `pure/paged.ts` 换算纯函数单测（TDD）：页↔比例边界（0/末页/中）、钳制、整除。
- 无 DOM 单测；面板手工目检：TXT/EPUB 各开一本 → 切翻页 → ‹ ›/点侧/方向键/滚轮翻页、页 N/总 N 显示、切章/重开进度还原、字号变列重算归位、高亮/摘抄跳转在翻页下到对页、翻页到章尾进下章。
- 回归 772 保持；tsc/esbuild/cmp 标准 gate。

## 裁剪（不做）

- PDF 翻页式已独立（pdf.js 真实页码），本批不并入模式切换。
- 不做翻页转场动画/翻书页角效果/双页书籍排版。
- 不做翻页模式下 TTS/听书。
- 进度不新增页字段（沿用百分比，理由见上）。

## 风险

- columns 列高与阅读区高需精确对齐（列断行、滚动条占位）；字号/窗口变 → 列数变化需重排归位（沿 ratio 保位置）。
- EPUB 现有双栏是设计偏好，翻页改单列需确保切换不破坏连续双栏（双栏仅连续模式保留）。
- 手势全开可能与正文选区/复制冲突（点侧翻页须避开选中态、文本可选中区）。
