# 阅读器 UI 重排批 1（仿 Readest 裁剪版）设计

> 日期：2026-09-03 | 状态：设计已确认（D1-D4 决策已定） | 范围：ReelLudic 阅读器（TXT/EPUB）界面重排——仿 Readest 沉浸式阅读界面，裁剪本批不做的功能
> 对齐参考：Readest（github.com/readest/readest，AGPL-3.0）阅读界面（用户实图：蛊真人阅读页，含左侧目录三 tab、顶部工具栏、底部进度翻页条、右上下拉设置）

## 背景与目标

阅读器现状（TXT/EPUB 同构，约 2079 行）：Modal 弹窗铺满（92%×90%）→ `rl-reader-head`（标题 + 进度文本 + ops：A±/行距±/目录 toggle/批注开关/关闭）→ 左侧 `rl-reader-toc`（目录 | 书签 双 tab 侧栏）→ 右侧正文滚动区（章标题 + 文本）。已有：章节目录跳转、字号/行距调整（写回设置）、连续滚动 + 翻章、进度持久化（章+比例）、摘抄回写笔记「## 摘抄」区（带 ^id）与书签 tab、选中摘抄（批注开关）。

本批目标：把 TXT/EPUB 阅读器界面**重排为仿 Readest 的沉浸式结构**（顶栏精简分组、左栏三 tab、正文选中动作条、右上下拉设置、底部章节+进度），并**裁剪**：不做搜索（整批砍掉）、不做听书/并排/词典/Wikipedia/批注详细编辑/登录同步。为批 2（高亮+标注列表）与批 3（翻译+DeepLX）留出动作条与 tab 位。

## 澄清结论（用户已确认）

| 决策点 | 结论 |

| 格式范围 | **TXT + EPUB**（连续滚动文本类同构）；PDF（pdf.js 翻页式）本批不动、后置 |

## 决策 D1：顶栏可见性（已定：D1b 自动隐藏，2026-09-03 修订）

**D1b 顶栏自动隐藏（仿 Readest 沉浸式）**：鼠标靠近顶部唤出顶栏（半透明渐变），移开或点击正文后自动隐去；也可点正文中央 toggle。顶栏不常驻，正文获得最大沉浸空间。
- 唤出机制：容器 `mousemove` 距顶部 ~48px 内显示；鼠标移出顶栏区域超过阈值（如 1.5s）隐藏；`Esc` 或点击正文中部也可切显隐。
- 样式轻量化（半透明渐变底、无重边框），隐藏时正文全宽可用。
- 说明：本批先做 TXT/EPUB；该交互在连续滚动正文下同样适用（顶栏本身浮于正文上方）。
- 撤销原 D1a（常驻半透明）。

## 决策 D2：设置下拉项目（已定：基础项，主题后置）

下拉只放「点击有实际作用」的项（Readest 多余项不出现，避免点了无反应）：

- ✅ 滚动模式状态（连续滚动当前值；翻页式置灰 title「后续版本」，不引入真翻页渲染）、字号 −/+（写回设置 `readerFontSize`）、行距 −/+（写回设置 `readerLineHeight`）、全屏显示
- ❌ 不出现：主题切换（**2026-09-03 修订：本批不做浅/深切换——阅读器内嵌 Obsidian 自动跟随系统/用户主题；EPUB iframe 主题同步后置**）、自动滚动、段落模式、快捷模式、登录后同步、自动主题、深色反图

> 「翻页式」实际渲染：见 D4 决策——本批**不引入真翻页渲染**，滚动模式开关仅作为未来批的 UI 预留项展示；如不希望出现无效项也可在实施时隐藏。

### 各区域改动（相对现状）

1. **顶栏（head 区重构；D1b 自动隐藏）**
   - 顶栏浮于正文上方，默认隐藏；鼠标靠近顶部 / 点正文中部唤出，移出后自动隐去（详见 D1）
   - 左：`目录`/`书签`/`摘抄` 三个 icon 按钮 = 侧栏三个 tab 的 toggle（替代现「目录 toggle + 批注开关」）
   - 中：`书名 · 格式`（保留）
   - 右：`A`（字号下拉或 −/+ 入口，D2）、`≡`（设置下拉，D2）、`✕`（关闭）
   - 移除现 ops 里分散的「行距− / 行距+ / 批注开关」，分别归入设置下拉（行距）与动作条（批注/摘抄 = 摘抄动作）；A± 字号保留顶栏快捷入口
2. **侧栏（rl-reader-toc 重构为三 tab）**
   - tab 由「目录｜书签」→「目录 | 书签 | 摘抄」
   - 目录 tab：章节目录（保留现状）+ 当前位置高亮
   - 书签 tab：**批 2 填充高亮/书签列表**；批 1 先做结构（空态「暂无书签」）
   - 摘抄 tab：承接现「书签」tab 的摘抄列表（回归笔记摘抄回写 + 点击跳原文段落）——**语义改名**，现有 `exTab`/`exPane` 数据与跳转逻辑迁移到「摘抄」tab
   - 移除侧栏底部「编辑/添加」类按钮（现状无，确认不新增）
3. **正文（滚动区）**
   - 正文居中留白更宽（实施时给定阅读栏 max-width，不做栏宽用户可调）
   - **选中文字浮动作条**（替代现「批注开关 + mouseup 弹摘录确认」的间接方式）：
     - ★ 书签：未选中文本 → 记当前章节+位置为书签（入书签 tab）；已选中文本 → 记选中范围书签（批 2 深化）
     - ❝ 摘抄：选中文本 → 复用现摘抄确认弹窗（ReaderExcerptModal）写回笔记「## 摘抄」；与现行为等价但入口更直接
     - 🖍 高亮：批 1 占位禁用（提示「批 2 提供」）或先行页内临时高亮标记——**见 D3**
     - 译：批 1 占位禁用（提示「批 3 提供」）
   - 动作条样式浮于选中文本上方（绝对定位、主题色圆角胶囊、多按钮）
4. **底部进度条**
   - 新增：章节名（当前章）+ 章内/全书百分比（D4a：不伪造页码）
   - 进度条：章内/全书百分比；章节边界 tick 可选（不引入真实页码）
   - 翻页（‹ ›）：沿用滚动语义（上一屏/下一屏，或翻章）；撤销/重做（读后回退/前进）P1 可选，批 1 至少交付位置记忆的「上一位置/下一位置」
   - 不放听书
5. **styles.css**：rl-reader-head/toc/tabs/ex/… 结构调整 + 新增：动作条（rl-selbar）、底部（rl-rfooter）、tab 激活态、半透明渐变；统一 Obsidian 变量（rl-* 规范，无硬编码色）

## 决策 D3：动作条「高亮/翻译」形态（已定：D3a）

**D3a 灰态占位**：高亮/翻译 icon 置灰可点（点击 Notice「该能力在后续版本提供」或 title 提示），批 1 只交付「书签 / 摘抄」可用 + 动作条框架。不做页内临时高亮（避免半成品误导）。

## 决策 D4：进度与翻页语义（已定：D4a）

**D4a 展示层近似，不伪造页码**：
- 底部左侧显示当前章节名；
- 右侧显示「章内进度 % · 全书进度 %」（沿用现有章+比例语义换算）；
- 翻页按钮（‹ ›）沿用滚动语义：上一屏/下一屏（或翻章）；
- 不引入 TXT/EPUB 真实页码（无固定页码语义），**真翻页式渲染不纳入本批**（列为后续预研项，见 D2 说明）。

## 数据模型 / Schema

- **零变更**：本批不新增 MediaEntry/阅读设置字段，不新建存储。
- 阅读设置（字号/行距）沿用现有 `readerFontSize`/`readerLineHeight`（写回设置）。
- 摘抄仍写笔记（沿用 excerpt.ts + ReaderExcerptModal 管道）；书签/高亮存储留批 2 设计。
- schema append-only 红线不受影响。

## 测试策略

- 纯逻辑变更趋近于零（重构 UI 为主）→ 无 TDD 新增需求；保留回归（现有 panel 行为：目录跳转、字号/行距、进度持久化、摘抄回写、书签跳段落）。
- 手工验证点（对照本文「目标界面结构」逐区目检）+ 产物符号断言。
- 真翻页式渲染不在本批（D4a），无分页逻辑测试需求。

## 范围边界（不做清单）

听书/TTS、并排阅读、阅读内搜索、词典/Wikipedia、批注详细编辑（Notebooks）、登录同步/云、自动滚动、段落模式、快捷模式、深色反图、PDF 面板、跨书全文搜索、导为摘抄（书内高亮→笔记的批量导出，批 2 视需求再定）。
