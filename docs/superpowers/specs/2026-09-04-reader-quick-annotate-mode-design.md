# 顶栏四快捷按钮「标注模式锁」设计（Auto-Annotate Mode）

> 日期：2026-09-04 | 状态：已实现（TXT+EPUB，791 全绿） | 范围：ReelLudic 阅读器（TXT + EPUB）顶栏左四快捷按钮
> 前置：高亮批（一键即黄即记 + 笔记「## 高亮」区 + 页内 `<mark>` 还原 + 标注 pane 列表/删除）已完成。

## 一、现状与问题

顶栏左四快捷按钮（TXT/EPUB 同构，`mkQuick`）当前**点一下即执行一次**，用完即走：
| 按钮 | 图标 id | 现状点击行为 |
|---|---|---|
| 书签 | bookmark | `activatePane('bm')`：打开左侧书签面板 |
| 批注 | quote | `activatePane('ex')`：打开左侧摘抄/批注面板 |
| 翻译 | languages | `quickTranslate()`：对**当前已选区**翻译 |
| 高亮 | highlighter | `quickHighlight()`：对**当前已选区**一键即黄即记 |

**缺陷**：高亮/翻译必须"先选中 → 再点按钮"，两步、且一次只能处理一个选区；没有"先定好接下来要干嘛、连续选中连续生效"的模式。用户想要的是一种**标注模式锁**：
- 点按钮 → 进入"激活(保持变色)"态
- 此后**每次鼠标拖选一段文字 → 自动执行该按钮功能**（无需再点按钮）
- 再点按钮（或切到其它按钮）→ 退出激活，选中不再触发

## 二、四按钮的标注用途定位（语义澄清）

**核心张力**：四按钮里只有 **高亮** 天然契合"每次选中即自动标注"。书签/批注/翻译若也对"每次选中"自动触发，会产生明显噪音或弹窗轰炸。故按"标注物/动作强度"分层定位：

| 按钮 | 标注语义 | 激活后「每次选中自动做」的合理行为 | 噪音度 |
|---|---|---|---|
| 🖍 **高亮** | 页内持久黄标（写笔记 ## 高亮） | **静默自动加黄标**，不弹窗、不打断，最贴合 | 低 → **主推** |
| ❝ **批注/摘抄** | 引录进笔记（带确认弹窗） | 激活后每次选中 → **弹既有摘录确认窗**（每选区一条，由弹窗把关） | 中 |
| ★ **书签** | 位置收藏（章+百分比+可选文字） | 激活后**单击正文即存一个位置书签**（按章去重：同一章已有书签则不重复建）——不是按文字 | 低 |
| 🌐 **翻译** | AI 划词翻译浮层 | 激活后每次选中 → **就地译文浮层**（自动翻、可连选连译） | 中 |

> 说明：书签本质是"位置标记"非"文本标记"，故书签模式的"触发"建议用**单击正文(无选区)**而非拖选；若用户能接受"拖选一段也建一个位置书签"，则与高亮一致用拖选。此点需用户拍板（见第五节）。

## 三、统一状态模型（两面板复用）

新增 `annotateMode: 'highlighter' | 'quote' | 'bookmark' | 'languages' | null`（null=未激活）。
- 点某按钮：若 `annotateMode === 该id` → **取消激活(null)**；否则设 `annotateMode = 该id`，并把对应按钮加 `.rl-quick-active`（保持变色/背景高亮），其余按钮移除。
- 按钮高亮样式：`.rl-quick-active { background: var(--interactive-accent); color: var(--text-on-accent); }`（Obsidian 强调底色，暗/亮自适应）。
- 进入激活时给已点按钮 title 提示（"模式已开启：拖选文字即自动高亮，再点退出"）。
- 模式在**切章/关闭面板**时自动复位为 null（避免残留）；侧栏交互(目录/面板滚动/选中非正文)不触发。

## 四、选中监听与分派

在现有 `onTextMouseUp`（TXT）/ `onFrameMouseUp`（EPUB iframe）**之前**插入一道：若 `annotateMode` 非空且有非空选区，则按模式分派并 `return`（不弹普通动作条 selbar）：

```
onTextMouseUp(ev):
  text = getSelection().toString().trim()
  if annotateMode === 'highlighter' && text:
      hideSelbar(); doHighlight(text, loc)     // 静默黄标（走既有一键即黄，已处理重复？见下）
      clearSelection(); return                  // 不清黄标，仅清浏览器选区
  if annotateMode === 'quote' && text:
      onExcerpt(text, undefined, loc); clearSelection(); return   // 既有摘录弹窗
  if annotateMode === 'languages' && text:
      showTranslateCard(...); return            // 就地译文浮层（保留选区对照）
  if annotateMode === 'bookmark' && 空选区(单击):
      addPositionBookmark(loc)                  // 位置书签，按章去重
  // 否则走原逻辑：弹普通选中动作条 selbar
```

**高亮静默自动**可额外配一个轻提示（如 800ms 小 Toast「已高亮」），避免连选时无反馈；可关。

## 五、重复选中 / 取消 / 清空（高亮为重点）

1. **重复选中同一段文字**
   - 现状 `doHighlight` 盲目追加 → 会重复。
   - **方案**：纯函数 `findSameHighlight(list, text, chapter)`（去空白归一比较 quote）→ 命中则**不新增**，提示「该段已高亮」，并把命中 `<mark>` 做一次短暂闪烁(2s class)定位告知。
   - 测试点：同 quote 同章去重；同 quote 跨章算两段（允许）。
2. **取消单条高亮（模式内）**
   - 激活模式 + 拖选到**已高亮段** → 走去重分支：二次点该段(或 Alt+点) = 取消该高亮。
   - 简化 v1：高亮模式下，拖选已高亮段自动**切换**（有→无，无→加），即"选中已高亮文字 = 取消该条黄标"。比去重更直觉，满足"点同段去高亮"。
   - 旁路：标注 pane（高亮列表）每条右键「删除」仍保留（已实现）。
3. **清除全部高亮**
   - 新增入口：标注 pane「高亮」区头部加「清除全部」按钮（防误触：confirm 一次）→ 逐条走 `onDeleteHighlight`，清空 `highlightList` + 重包 mark（无黄标）。
4. **翻译/批注模式无"清除"概念**（不落持久黄标），无需清空。

## 七、已拍板决策（用户确认 2026-09-04）

1. **四按钮都做 auto-lock**（非仅高亮）：高亮=自动黄标、批注=每次选中弹摘录确认窗、翻译=每次选中就地浮层、书签=激活后单击正文存位置书签。
2. **高亮重复段 = toggle**：高亮模式下选中已高亮段 → 取消该条黄标；选中未高亮段 → 新增。（不再做"提示已高亮不新增"）
3. **书签触发 = 单击正文(无选区)**：激活书签模式后，单击正文任意处存一个位置书签（按章去重），不依赖选区文字。
