# 05c-v0.3 验证清单（跨库统计与体验增强）

> 2026-08-27 | v0.3.0 实现完成（290/290 全绿，已部署测试库）。此清单供用户参考验证；交付时用户授权一次性收尾（跳过逐项确认）。

## 1. 三库分区统计（统计页）

- [ ] 统计页出现「三库分区」卡：书籍 / 影视 / 游戏 三列
- [ ] 各列计数正确（读完/看完/通关 = watchedDate 落在当年；在读/在追/玩过）
- [ ] 书籍列显示 已读页数 + 摘抄数；影视列显示 观影小时 + 追剧集数 + 电影/剧集/动画细分；游戏列显示 游玩小时 + 记录数
- [ ] 各列 Top3 点击可打开对应笔记；空榜显示「本年暂无…」
- [ ] 月度趋势三组柱状（书籍绿/影视蓝/游戏橙），hover 显示「N月 · N 部」

## 2. 年度总结

- [ ] 统计页快捷入口「📊 生成年度总结」→ 自动打开 `ReelLudic/reports/2026-年度总结.md`
- [ ] 报告含：frontmatter（type/year）+ 年度概览（三库计数/时长/摘抄）+ 三库 Top5 评分榜（双链）+ 月度节奏表（1-12月×三库）+ 完整双链清单
- [ ] 报告内 `[[标题]]` 可跳转到对应条目笔记

## 3. 封面本地化

- [ ] 设置 → 封面 → 开关「封面本地化」可切换并保存
- [ ] 开开关后新条目保存：网络封面下载到 `ReelLudic/covers/{id}.ext`，poster 变相对路径，海报墙正常显示
- [ ] 「立即迁移」：存量 URL 封面逐个下载（限速），结束 Notice「成功 N/失败 M」；再点一次仅处理未本地化项（幂等）
- [ ] 断网/图床失效时本地封面仍可显示

## 4. 数据导出/导入

- [ ] 设置 → 数据管理 →「导出 JSON」→ `ReelLudic/backups/catalog-时间戳.json` 生成
- [ ] 修改若干条目后「从备份恢复」→ 选择备份 → Notice「新增 N/跳过 M」；已存在条目（标题+类型重复）不被覆盖
- [ ] CSV 批量导入：准备 `title,type,status,rating,year` 表头 CSV → 选择文件 → 合并去重导入 + 汇总；未知 type/空标题行跳过

## 5. 批量栏增强

- [ ] 列表视图勾选条目 → 批量栏出现
- [ ] 批量评分：选 1-5★ → 应用 → 选中条目统一评分；「清除评分」→ 评分置 0
- [ ] 批量标签：输入逗号分隔标签 → 应用 → 选中条目追加合并（不覆盖已有）
- [ ] 原有批量改状态 / 删除 / 取消选择仍正常
