## 1. 页签切换（7 Tab）

| ☐ | 步骤 | 预期 |
|---|---|---|
| ☐ | 依次点击「计划表 / 书籍 / 动画 / 剧集 / 电影 / 游戏 / 统计」 | 7 个页签均可切换，Tab 计数徽标显示对应条目数 |
| ☐ | 计划表页签内切换「追更表 ↔ 月历」 | 两种视图正常切换，无报错 |
| ☐ | 统计页签 | 仪表盘渲染（能量环/最近动态/类型分布/快捷入口/活跃热力图），空库时也不报错 |

## 2. 添加流程（4 路）

| ☐ | 步骤 | 预期 |
|---|---|---|
| ☐ | 电影页签点「＋ 添加」→ 搜索（有 TMDB Key） | 弹窗初始类型=电影；搜索回填封面/导演/演员/年份/简介，可覆盖 |
| ☐ | 书籍页签点「＋ 添加」→ 搜索 | 初始类型=书籍；Google Books → Open Library → 豆瓣三级兜底，命中任一即回填 |
| ☐ | 游戏页签点「＋ 添加」→ 搜索（无 IGDB 凭据） | 明确引导提示去设置页配置，不静默失败 |
| ☐ | 手动添加（任意类型，不搜索） | 表单录入成功，保存即生成笔记 |

## 3. 状态切换 + 追更 + 月历

| ☐ | 步骤 | 预期 |
|---|---|---|
| ☐ | 卡片状态徽章点击 → 四态菜单 | 想看→在看→已看，任意→弃剧；不合规跳转置灰不可点 |
| ☐ | 书籍条目状态切换 | 文案显示「想读/在读/已读/弃读」（非观看语义） |
| ☐ | 剧集条目「＋1 集」/ 追更表「已更新」 | 集数+1、写更新日志、卡片置顶重排 |
| ☐ | 追更表「重新检测」（有观看链接的条目） | 抓取网址 HTML 提取最新集数，返回检测结果；无链接/被屏蔽页给出提示 |
| ☐ | 月历：想看条目设置计划日期 | 按 plannedDate 落到对应日期格；点击日期打开当天详情弹窗 |

## 4. 笔记生成

| ☐ | 步骤 | 预期 |
|---|---|---|
| ☐ | 添加影视条目后打开详情笔记 | frontmatter 含 id/type/title/status/rating/year/genres/progress_*；正文含基本信息/个人评语/观看链接 |
| ☐ | 添加书籍条目后打开详情笔记 | 书籍属性行（作者/出版社/ISBN/译者等）；frontmatter 含 reading_page/reading_total_page（若填了进度） |
| ☐ | 笔记失败降级 | 手动断网/异常时保存不阻断：条目已落库并刷新，提示区分「已保存但笔记失败」 |

## 5. 删除条目

| ☐ | 步骤 | 预期 |
|---|---|---|
| ☐ | 编辑弹窗 → 删除条目 → 二次确认 | 条目从书架消失，对应 .md 笔记连带删除，界面立即刷新 |
| ☐ | 删除不存在的文件（边界） | 静默成功不报错 |

## 6. 即时刷新

| ☐ | 步骤 | 预期 |
|---|---|---|
| ☐ | 添加/编辑/状态切换/追更标记/删除后 | 界面立即反映最新数据，无需手动刷新 |
| ☐ | 外部修改 catalog.json（用编辑器改） | 500ms 内界面自动同步 |
| ☐ | 外部删除 entries/ 下笔记文件 | 500ms 内界面自动同步 |

## 7. 重启持久化

| ☐ | 步骤 | 预期 |
|---|---|---|
| ☐ | 重启 Obsidian（或 Reload） | 数据完整、进度不丢、页签状态保持，catalog.json 与笔记一致 |

## 8. 边界

| ☐ | 步骤 | 预期 |
|---|---|---|
| ☐ | 空库状态 | 书架/追更表空态引导正常，无报错 |
| ☐ | 无 TMDB Key 搜索 | 明确引导去设置页，可走手动录入 |
| ☐ | 无网络/超时 | 搜索友好降级（提示+手动录入不阻塞），连接测试显示耗时与状态 |
| ☐ | 色彩主题切换（设置页：彩色/单色） | 书架卡片类型色条开/关即时生效，明暗主题下均可读 |
