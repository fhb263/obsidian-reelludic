## 2. 重构目标

1. **信息架构重排**：数据主体（四库分区 + 趋势）升为第一视觉层级；砍掉装饰性与低信息密度块。
2. **数据优先视觉**：全量回归 UI-GUIDE——CSS 变量、无渐变/发光/动效/彩色阴影/emoji，图标统一 Icon(Lucide)。
3. **只算今年**：所有统计口径保持"今年"（不变更年份切换器）。
4. **历史回顾**：新增「往年报告」入口（列出已生成的 YYYY-年度总结.md，点击打开），今年报告可生成。
5. **丢弃**：年度目标（localStorage 字段与圆环 UI 一并移除）。

## 4. 视觉规范（对齐 UI-GUIDE，逐条可验收）

- 色：仅 Obsidian CSS 变量（背景/文字 3 级/边框/`--interactive-accent`）；类型语义色仅用于**折线/色点/小徽标**且保持低饱和（book #6aa87a / media #5b9bd5 / game #d99b53 / music #2AA89B 降饱和后使用）。
- 图标：统一 `<Icon>`（Lucide，随主题变色）——分区头 book-open/film/gamepad-2/music；快捷 dice/shuffle·list·plus；实现时以 obsidian 内建 lucide 集为准验证图标名。
- 禁：渐变填充、backdrop-filter、呼吸/流光/旋转动画、彩色 box-shadow、3D 倾斜、emoji 图标、硬编码色值。
- 卡片：`--background-secondary` 或色值淡化的统一背板、1px 边框、8–10px 圆角、gap 10–12px；KPI 主数字 20–24px/700，标签 10–11px muted/faint。
- 双主题：浅色浅卡片、暗色自动随变量，无需手动 override（删除现有 body.theme-dark 特判中非必要部分）。
