# 14-跨库统计需求澄清（v0.3）

> 2026-08-27 | 状态：grilling 两轮收敛，决策已锁定 | 范围：跨库统计与体验增强（四里程碑全做）

## 背景

三库（影视/书籍/游戏）功能链已完整，统计页（StatsBoard Bento Grid）有基础模块但缺深度。v0.3 目标：**把收藏数据变成可感知、可回看、可分享的资产**——统计深度、年度总结、封面本地化、数据导出导入。

## 需求澄清结论（grilling 两轮，9 决策）

| # | 待拍点 | 决策（用户确认） |
|---|--------|------------------|
| Q1 | 统计口径 | **方案 A**：「看完/读完」= `watchedDate` 落在年内（三库统一）；「活跃」= 任一动态时间戳（watchedDate / progress.history / playSessions.date / plannedDate）落在年内 |
| Q2 | 年度总结入口 | **仅统计页按钮**（Stats 标签页内），不做命令面板命令；内容全量；落盘 `ReelLudic/reports/YYYY-年度总结.md` |
| Q3 | 封面本地化 | **存量全量 + 新条目增量**；开启设置后后台逐个下载（限速 300ms/张）；poster 替换为相对路径 `covers/{id}.jpg`（原 URL 已在 sourceUrl） |
| Q4 | 导出/导入/批量 | 四块全做：JSON 快照导出恢复、CSV 基础字段导入（合并去重）、批量评分/标签 |
| Q5 | 年度总结年份 | **仅生成当年**（按钮直接生成当前年，无年份选择） |
| Q6 | 统计页新卡 | **四卡全上**：时长聚合（观影/追剧/读书/游戏）、状态×类型矩阵、月度看完趋势柱状、年度高分榜 Top5 |
| Q7 | 封面迁移失败处理 | **失败跳过 + 计数 + 迁移结束 Notice 汇总**（成功 N/失败 M）；不自动重试（防反爬）；再点迁移只处理未本地化项 |
| Q8 | 导出/导入入口 | **设置页按钮**（JSON 备份/恢复、CSV 导入均从设置页触发；恢复/导入合并去重按 title+type） |
| Q9 | 批量增强 UI | **批量栏加评分（星级）+ 标签（逗号分隔）**，与现有改状态/删除并列 |
