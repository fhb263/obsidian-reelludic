| # | 屏幕 | 线框要点 | 高保真交互 |

## 2. 设计决策与依据

1. **视觉基调贴合 Obsidian 亮色主题**：灰白面板 + 紫色强调（#7c6cd9），全部 CSS 变量，天然适配用户主题切换。
2. **信息架构三视图**：书架（浏览/筛选）↔ 追更（连载管理）↔ 录入（添加），Ribbon + 命令双入口，与 DESIGN.md 的视图 ID 对应。
3. **海报墙自适应**：CSS grid `auto-fill, minmax(96px,1fr)`，视图宽度变化自动增删列（Obsidian leaf 宽度不固定）。
4. **状态机交互**：四态菜单中不合规回退（如 已看→想看）置灰不可点，规则与 pure/status.ts 校验一致。
5. **抓取降级前置**：录入表单顶部明示「数据源 TMDB」，无 Key 时搜索禁用并引导去设置页；豆瓣兜底开关默认关闭，附反爬风险提示——与 G2 降级预案一致。
6. **保存即生成笔记**：表单底部按钮文案「保存并生成笔记」，明确「写 catalog + 生成 .md」的副作用。
