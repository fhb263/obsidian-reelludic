## 2. 设计决策与依据

1. **视觉基调沿用 v0.0.1**：灰白面板 + 紫色强调（#7c6cd9），书籍语义色绿色（#3d7d5f）用于进度/页码，全部 CSS 变量适配主题。
2. **摘抄区位置固定**（评语后/链接前）：既是阅读顺序（先想法后证据），也是合并写入策略 C 的提取边界（08-开发可行性 §3）。
3. **命令式录入**：`添加摘抄` 命令 + 剪贴板自动带入 + 清格式，主操作 4 步内完成；页码可选不阻塞——对应 UX 视角「30 秒工作流」指标。
4. **双轨进度**：页码/百分比任一填写自动换算（仅展示层，存储以用户输入为准，防往返误差）；复用已就绪的 `readingProgress{page,totalPage}`。
5. **摘抄块即 Markdown**：`> 引用` + `p.xx` + 心得 + `^id`，用户可直改笔记（合并写入不回写摘抄区），符合 Obsidian「所见即笔记」。
6. **卡片信息密度分级**：在读卡片信息最全（进度条+页码+摘抄数），想读/已读简化——避免书架噪音，摘抄数徽标轻量（纯数量）。
