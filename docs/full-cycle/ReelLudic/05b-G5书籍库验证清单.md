## 6. 摘抄录入（核心）

| ☐ | 步骤                   | 预期                                     |
| - | -------------------- | -------------------------------------- |
| ☐ | 外部复制一段文字 → Ctrl+P →  | 弹窗打开，**剪贴板文本自动带入**引用框                  |
| ☐ | 填页码（如 128）+ 搜索选择挂载书目 | 书目列表显示库内书籍（标题+作者），点击选中                 |
| ☐ | 填心得（可选）              | 预览区实时显示将生成的摘抄块（引用 + p.128 + 心得 + ^id）  |
| ☐ | 点「生成摘抄」              | Notice「已添加摘抄 · 现有 N 条」；文本清空可连续录入（书目保留） |
| ☐ | 连续录入第 2 条            | 计数 N+1                                 |
| ☐ | 空引用 / 未选书            | 生成按钮禁用                                 |

## 7. 摘抄存储与双链（核心）

| ☐ | 步骤                  | 预期                                                       |
| - | ------------------- | -------------------------------------------------------- |
| ☐ | 打开已添加摘抄的书目笔记        | 有「## 摘抄」章节（个人评语后/链接前），含引用文本 + **p.128** · 心得 + `^bk…` 锚点 |
| ☐ | 编辑该条目（改评分等）→ 保存     | 笔记重写后**摘抄区原样保留**（合并写入策略 C 生效）                            |
| ☐ | 任意笔记写 `[[书名#^bk…]]` | 点击跳回书目笔记对应摘抄块                                            |
| ☐ | 摘抄区外（个人评语）出现 `^xxx` | 不计入摘抄数                                                   |
