## 给谁用

- **Obsidian 用户**，习惯用 Markdown + 双链管理一切，不希望收藏散落在不同 App 里。
- **收藏控 / 追剧党 / 影视爱好者**，需要记录「想看什么、看到哪了、追什么连载」。
- 未来扩展：**读书人**（书籍库 + 阅读器批注）、**游戏玩家**（游戏库 + 游玩记录）。

## 解决什么问题

1. **Obsidian 擅长笔记，但不擅长收藏管理**——没有结构化目录、没有封面墙、没有状态流转。
2. **收藏 App（Serpent / 豆瓣 / TMDB 站）不擅长笔记**——数据锁在应用里，无法双链、无法批注、无法版本管理。
3. ReelLudic 的答案：**把收藏变成 Obsidian 库里的结构化资产**（JSON 目录 + Markdown 笔记），收藏即笔记，笔记可双链。

## 成功指标

- **可用性**：从零添加一部影视到「书架展示 + 追更」< 1 分钟

- **可移植性**：`ReelLudic/` 目录拷走即迁移，JSON 可读、MD 可编辑
