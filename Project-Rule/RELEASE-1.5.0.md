## 1.5.0（2026-11-07）

> 对照基准：**1.4.0（2026-10-25）** → **1.5.0（2026-11-07）**
> 编写口径：**只写最终用户可见的形态**，开发期反复推翻或中途实现过又撤除的方案一律不入本文（已撤除项统一归到「其他调整」）

### ✨新增功能

- 选集详情页（B 站风独立页）：从系列卡片的播放按钮进入的不再是弹窗，而是独立页面，系列信息 / 选集网格 / 简介三卡独立
- 选集页内置播放器同屏：点集即在同页播放，不跳窗
- 选集页每段 50 集分页（新页面七列，比弹窗宽得多；选集弹窗仍按 100 集分页，两个常量分属两个场景）
- 选集页保位口径与旧弹窗一致：下标恒等于第几集，空位留洞不压缩，避免第 2 集之后的路径 / 地址 / 集标题整体前移
- 网络集官方内嵌播放：B 站 `player.bilibili.com/player.html?bvid=…`（支持 `?page=2` 切分P）、YouTube `/embed/`，就地播放不跳浏览器
- 网络集登录态自动带入：挂 iframe 前把设置里填的 Cookie 同步进 Electron 的 cookie jar，否则填了也永远是「未登录」
- 网络集拼不出内嵌地址时自动降级「在浏览器打开」，不报错不白屏；换集只改 `src` 不重建节点（重建会闪白）
- 字幕时间轴面板：每行 `[时间戳] [字幕文本]`，时间戳等宽小字，当前行高亮，未锁定时自动跟随滚动
- 字幕锁定提词器：锁定后字幕固定在容器内的位置（默认第二行），长句不再滚走
- 字幕多语言切换：按语言给选项，支持 B 站 / YouTube 多轨字幕
- 字幕空态拆开：没有字幕、正在解析、未登录各自文案不同，不再把三种空结果混成一句「没有开放字幕」，且按平台分别提示
- 字幕 AI 总结 / 提问：时间轴旁一颗 AI 小图标，总结整条字幕全文，按剧情推进分点，要求不剧透结局、不编造原文没有的情节
- 字幕 AI 总结按固定节奏逐字浮出：不再等模型全部返回才一次性铺满，长摘要边等边读；要点仍等整份结果到达后一次性列出
- AI 提问回答流式打字机：逐字出现，可暂停、可跳过、切走即停，不留孤儿定时器；解析对代码块与多余解释容错
- 学习模式 · 单句循环：双击任意字幕行，该句左侧出现 🔁，视频在句子首尾之间反复播，再双击取消
- 学习模式 · AB 复读：右键两句分别设 A / B，顶部横幅 `A [00:12] ←→ B [00:45]`，在该区间循环
- 学习模式 · 影子跟读：一句播完自动暂停 → 倒计时 → 自动播下一句
- 字幕悬停查词：鼠标停在字幕词上出释义，可点 🔊 发音；词典是本地文件（ECDICT 精简 CSV 或自备「词<TAB>释义」表），没配也能用
- 本地语音转文字：全部在本机完成、不上传，把音视频里的声音识别成字幕
- 六家引擎可切换：whisper.cpp（内建）/ SenseVoice / Paraformer（sherpa-onnx 离线版）/ X-ASR（sherpa-onnx 在线版）/ Qwen3（自备 Python 环境经桥接脚本调用）/ Confucius4（本地大模型多模态）
- 模型列表平铺单选：六家的每个档位摊在同一张表里，体积与中文 / 英文准确度一眼可比，不用先选家再展开下拉
- 三档模型一键下载：按能力档位命名为极速 / 均衡 / 精准，技术名只做小字副标题，另有更大档位可选
- 每家引擎一枚品牌标记：按各家技术特征自绘的极简图标，随主题变色，不是通用房子图标
- 安装清单逐项打勾：点「一键装好」先弹窗列出**要装哪几样、每样多大**，装一样打一个勾，进度按「第几项 / 这一项百分之几」报
- whisper.cpp 运行时可一键安装：从官方 release 按白名单只取真正需要的 5 个文件（约 3.1MB），不解压整包
- 模型按引擎分目录 `models/<engine>/`：一眼看出哪个文件属于哪一家，也能单独清掉某一家的模型
- 外部程序自动定位：机器上已经装过、或插件已经下好的，不再反过来问你「路径填哪儿」；只有真的找不到才要你指路
- AI 运行管家 · 环境体检：显存多大、CUDA 在不在、编译工具链什么版本，逐项给出结论与能否跑某档模型的判断
- 转写进度浮球：点转写后可切去别的笔记干活，右上角悬浮球持续显示进度与阶段文案，任务不随视图卸载而中断
- 同步弹窗统一三段式说明：每个同步弹窗都按「**同步数据** / **冲突处理** / **前置条件**」三段写，扫三个词就知道同步什么、会不会覆盖、要先准备什么
- 列表按属性归类：全类型视图下把条目按时间跨度 / 类型等属性归成一级组卡，点卡进组看组内；组内原有的系列折叠卡照旧，两级各用各的机制
- 网络集无字幕分两种说法：Cookie 没填或过期 → 指路去重填；Cookie 有效但取不到字幕轨 → 如实说这一集没解析出字幕。不再用一句话糊过去，也不再给出「去平台看这一集」这种没用的出口
- 分类视图：首页在原有分类胶囊栏上方加一条视图切换，含默认视图 / 合集视图 / 自定义视图
- 合集视图（新视图类型）：先出 IP 卡片，点进去才展开子系列行（带左侧引导线 + 旋转箭头），按 `series` 聚合，不猜类型与标题前缀
- 自定义视图按标签筛：条目 `tags` 命中即属于该视图；视图定义存进媒体库跟库走，换设备 / 同步后分类结构一致
- 物理目录结构一字不动：视图只是同一份 entries 上的过滤器
- 条目属性面板：高级设置 › 条目属性，自由删减各类型条目在编辑弹窗里的属性块，支持显示 / 隐藏、先后顺序、每块占几栅格，书籍三子类各一份
- 从笔记导入条目：设置 › 基本设置 ›「从笔记导入条目」点「检索」→ 扫描笔记目录 → 弹窗勾选 → 落库 → 回写 id
- 导入白名单判据：只认六个合法 `type` 值，且必须能读出非空、非占位符的 title，避免把自定义 type 与模板占位符一键倒进来
- 评分看板支持系列合集分：独立字段，不回落组内平均，可排序、可查看

### ⚡体验优化

- 四类阅读器侧栏统一（PDF / EPUB / TXT / 漫画）：书签、摘抄、高亮、截图各处的位置与交互一致
- PDF 阅读器：高亮只存 JSON 不写回 PDF 原文件（零损坏风险）+ 摘抄 + 区域截图回填笔记 + 双模式翻页
- 漫画阅读器：缩略图同步滚动 + 连续滚动
- 播放器：网络集时间戳可跳转，并在时间戳列表里显示
- Ctrl + 滚轮缩放字号 / 页面大小；可隐藏插件内滚动条（含编辑弹窗）
- 设置页六页签结构稳定：基本设置 / 元数据源配置 / 播放阅读 / AI集成 / 高级设置 / 关于
- 「播放阅读」页：媒体载体（内置阅读器 / 视频播放器 / 音乐播放器的开关）+ 语音服务（🎙️ 语音转文字 + 🔊 文字转语音，各一张一体化卡片）
- 凭据类输入框统一「标识在上、密钥在下」；网络源支持就地校验，测试结果不再推走按钮
- 元数据搜索源每个勾选项悬停 2 秒出轻提示（说明这个源强在哪）；描述里的官网地址变成可点击超链接
- Steam 同步改成先弹窗列出游戏供勾选，补齐封面与元数据；评分改为好评率百分比（双源同源化）
- TMDB 想看清单 / 收藏接入；Bangumi 收藏导入
- 豆瓣一键读取全部收藏，类型 / 状态降级为过滤条
- 统计页五个区块自由排序 + 自适应；评分看板改版
- 卡片信息栏改用控件配置，支持每块半行、容器查询重排

### 🎨界面美化

- AI 集成页「用途」组改主从布局：左索引（七条状态一眼看全，带状态点）+ 右详情（只编辑当前这条），不再平铺纵向无限拉长
- 提示词从折叠块改成常驻多行输入框：失焦自动保存，脚下实时显示「已自定义 · 共 N 字」与「恢复默认」
- AI 模型选择器改为弹窗，不再是一长条下拉
- 模型服务卡：LobeHub 图标 + 卡片组织，两张自定义端点槽位可重命名
- 四阅读器侧栏统一为「推挤式」：内容随侧栏推开，不遮挡
- PDF 顶栏七钮统一；漫画书签 + 截图入口统一
- 选集页三卡独立，深色 / 浅色主题均验证

### 🐛问题修复

- 修复网络集字幕恒报「没有开放字幕」：只问了两个字幕接口中的一个，两者轨集互有出入 → 取并集（去重键用 `lan`），并叠加跨限流窗口的重试
- 修复未登录时谎报「没有歌词」：把「未登录」与「没有字幕」两种空结果分开，不再说假话
- 修复同步导入的 Steam 条目没有评分：两个落库入口各写一份映射，漏了一处
- 修复同步弹窗勾了「库里已有」却被当同名跳过：判重早于覆盖判定
- 修复 TMDB 同步必然失败：路径单复数 + 把 v4 的 `access_token` 当 v3 的 Key 用，两层根因叠加
- 修复「立即同步」提示推开按钮：提示槽从行内挤占改成不推移布局
- 修复 AI 服务「不启用」却亮着模型名：`off` 归一化回落到默认服务商，再取回该家默认模型，盖掉了「不启用」文案
- 修复提示词标签重复渲染：调用方画一次、组件内部又画一次，同一句「提示词」出现两遍
- 修复提示词保存后提示不刷新：「已自定义 · 共 N 字」与按钮禁用态停在旧值，改为回读输入框现算
- 修复搜索结果退出不清：退出即清，不再下次进来还是上次的
- 修复漫画侧栏被顶栏遮挡：层级 / 滚动容器修正
- 修复侧栏宽窄不按阅读器独立：宽度按阅读器分开存

### 🔧其他调整

- 默认值收紧：新装时元数据源默认「仅豆瓣」、AI 用途默认全部「不启用」，开箱即干净
- 默认值不做一次性迁移：已存过设置的老用户原样保留，不覆盖你的显式选择
- 网络集最终只保留「官方 iframe 内嵌」一条路；开发期的插件自取流（DASH 分片 + MSE 双轨 + 本地代理绕防盗链）已整体撤除，不属于 1.5.0 的功能
- B 站视频字幕作为 LRC 歌词第五源（wbi 签名）整条链路撤除，在线歌词源回到四源（网易云 / 酷我 / QQ / 酷狗）
- AI 用途不采用「四行各自成卡」，最终改为左索引 + 右详情的主从布局
- 分类视图入口从「高级设置」末位提到第一顺位并加图标
- 音频转文字从「高级设置」搬到「播放阅读 › 语音服务」
- 选集弹窗四列 / 侧栏渐隐 / 集数分区选项卡等中间形态被后续批次取代，只保留最终形态
- 升级无需迁移操作：版本号升到 1.5.0，数据目录、`catalog.json`、笔记 frontmatter 键名全部不变
- 外部程序按需自备：语音转文字需要 whisper.cpp（可一键装）或 SenseVoice / Paraformer / X-ASR / Qwen3 / Confucius4 环境（后五家插件能逐项体检并给出安装清单，不必自己拼）；查词需要自备词典文件；网络集下载相关功能需要 yt-dlp——不装也能用插件其余全部功能
