# ReelLudic 1.2.0 更新日志

> 2026-10-04。供 GitHub Release / 群公告直接粘贴。**面向使用者**写，不掺内部批次号；
> 逐条技术细节与判据见仓库 `CHANGELOG.md`（用户向）与 `Project-Rule/CHANGELOG.md`（技术向）。

---

> 本版定级 **1.2.0**（内部编号 1.1.1 改定）：这一版装的是实打实的新功能面 —— 音乐下载、书源与书籍下载、
> 系列合集、追剧、阅读器读取进度等，按语义化版本属于 minor 升级。
> 逐条技术细节与判据见 `Project-Rule/CHANGELOG.md`（技术向）。

### 新增分组与显示

- 阅读视图新增「漫画」子分组。
- 编辑表单新增「系列」与「系列序号」；同一系列的多部作品会自动折叠。书籍类折叠卡的阅读进度条按部均分。
- 新增「AI 预填字段」小图标按钮，仅在手动填写条目界面显示；可按标题预填条目字段，便于处理搜索不到的小众条目。

### 音频播放器

- 可在插件页-基本设置-实验性功能-启用内置音频播放器。
- 可在独立标签页打开，也可拖入侧边栏；若侧边栏已在播放，会直接切歌，不再新开页面。
- 支持网易云、QQ、酷狗、酷我搜索下载，以及 B 站音频流（需 yt-dlp 与 ffmpeg）。
- 新增「音乐下载」小图标按钮，下载后自动关联到条目的本地音频路径。
- 新增「获取歌词」「AI 双语歌词」小图标按钮，结果写入笔记内并渲染。
- 新增「检索同名音频文件」按钮，可批量关联本地音频，并支持重命名。

### 体验优化

- 音乐条目新增「酷我在线曲库」搜索栏。
- 封面新增「从网络搜索封面…」选项，可通过 Bing 搜索并下载图片作为封面；音乐类型条目也可从网易云、QQ、酷狗、酷我的歌曲封面中下载作为封面。
- 影视类条目关联网络链接时，新增 B 站搜索回填 URL 与剪贴板「粘贴」按钮。
- 手动添加条目支持填写来源名、大众评分、评分人数与平台链接，并支持再次编辑。
- 简化「当前进度」显示；当前集按钮增加边框高亮。
- 「从文件夹检索剧集」会同时填入集标题。
- 「选择集数」窗口移除滑动条，优化按钮对齐与悬停提示。
- 「获取歌词」与「总结摘要」旁新增加载转圈指示器。
- 「数据源配置」更名为「元数据源配置」，并新增音乐源凭据入口。
- 实验性功能开关统一命名为：启用内置阅读器 / 视频播放器 / 音乐播放器。
- 统计页「动态」不再并排显示两个「已看」。
- 精简若干条界面悬停提示与设置说明。
