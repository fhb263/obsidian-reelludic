## 快速事实

- **数据源**：10 源注册表——Douban（全类型主力，含反爬适配）、TMDB（影视）、Bangumi（动画），辅助源 Open Library / Google Books / Steam / MusicBrainz / iTunes / OMDb / AniList；每类型源链设置页可自选
- **存储**：`媒体库/catalog.json`（事实源）+ 详情笔记 `.md`（展示/双链层，笔记内容打开表单时回填）；目录已中文化（笔记/封面/备份/报告）
- **测试**：**896 单测**（57 文件，全绿基线 2026-09-09）
- **构建部署**：`npm run build`（rm 强制重建）→ 三产物拷贝 `build/` 与测试库 + `cmp` 校验
- **最新功能**：统计页完全重构（KPI 行/四库分区/月度趋势×今年动态/往年报告）、影视进度手填（S/E）、列表进度列克制、全项目按钮 hover 统一、排期表月/周历等高 + 周历点击弹详情、内置播放器与 TXT/EPUB/PDF 阅读器
