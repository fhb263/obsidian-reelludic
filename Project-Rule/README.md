## 快速事实

- **数据源**：**13 源注册表**（真源 `src/pure/sourceRegistry.ts` 的 `PROVIDERS`）——Douban（全类型主力，含反爬适配）、TMDB（影视）、Bangumi（动画 / 漫画）、**MangaDex（漫画）**、**微信读书（书籍，Cookie 可选）**，辅助源 Open Library / Google Books / Steam / MusicBrainz / iTunes / OMDb / AniList / IGDB；**6 组源链**（书籍/漫画/游戏/音乐/影视/动画）设置页可自选。⚠️ 别写少 IGDB / MangaDex / 微信读书，也别信「已移除 Google Books / Open Library」（它们都在册，只是默认链关着）
- **存储**：`媒体库/catalog.json`（事实源）+ 详情笔记 `.md`（展示/双链层，笔记内容打开表单时回填）；目录已中文化（笔记/封面/备份/报告）
- **测试**：`tests/*.test.ts` 现有 **186 个测试文件**（2026-10-07 实测）；🔴 **一律不跑全量 vitest**（2026-09-28 加严）—— 只跑**受影响**单测（动公共纯逻辑才全量）；判绿必须 `exit` + 逐行 `FAIL` + **PASS 总数**三件一起看（⛔ 不看横幅）；跑单测**必须先 `cd` 到项目根**（见 `AGENTS.md` 已知坑点表）
- **构建部署**：`tsc` + `node esbuild.config.mjs production` → `node _deploy.cjs`（三产物 md5 **三方一致** 后落测试库）→ 产物断言 → 突变验证；收口才算完（详流程见 `AGENTS.md`）
- **最新功能**：内置播放器（自绘控件，画面撑满内容区、只能关标签页退出）与 TXT/EPUB/PDF 三阅读器（六档阅读主题、高亮三样式×五色、书签/摘抄 callout 化、顶栏「打开笔记」）、**双向溯源**（点笔记里的摘录链接直接跳回原文定位）、TXT 编码嗅探（GBK/UTF-8/UTF-16 自动识别）；🔴 **PDF 阅读器高亮（2026-10-23，路线 A）**：拖选 → 动作条「高亮」一次点击即按默认样式落一条（色板随后浮出可换样式×五色）、侧栏第三个页签「高亮」列出/跳转/右键删除、位置存归一化百分比矩形（缩放 50%–300% 不跑偏）、**只写 `阅读进度/*.json`，⛔ 不改 PDF 文件本身**；PDF 动作条只三钮（高亮/复制/垃圾桶），摘抄·翻译·搜索·AI 这四项 PDF 不做；**海报墙密度 + 题材筛选 + 封面评分角标 + 统计页三层 + 设置页顶栏 Tab + 阅读器顶栏标题居中 + 媒体库目录搜索式选择**；**音乐下载**（四平台搜索/试听/下载，`fee` 判可下载性、64KB 魔数防伪）与**书籍下载**（🔴 **只剩「书源检索」一条内容通道 · 书源由用户自备**，📌 插件**不内置任何内容源**；多源并行搜书 → 章节范围 → 抓成 TXT/EPUB → 自动写回 `bookFile`，抓章并发 50、取消真取消、断点续传自动）；**海报墙系列折叠卡**（同一类型下同名系列 ≥2 条自动折叠 → 点卡片进「这一系列自己的视图」／点右下角圆钮弹**居中弹窗**按封面网格挑一部播或读）；**漫画子分类加回**（阅读页签四桶【全部 / 文学 / 网文 / 漫画】＋ 独立源链组 豆瓣 / Bangumi / MangaDex，表单增「画师」与「总话数」、独立 `笔记/comic/` 目录）；1.1.1 为长期巩固版（⚠️ 2026-09-22 用户裁定「**体验优化不算新增功能**」，故这类完善仍进 1.1.x）；**1.3.0 期**另收进：第三档导航布局「**合并视图**」（取消顶端独立筛选行，媒体类型 / 状态 / 排序三下拉与一枚「更多」菜单并入内容区与工具栏）、**海报墙阅读进度与数字并排**（撤销「条贴封面底边」）、**基本设置页改回 Obsidian 原生分组样式**（核心 `.setting-group` / `.setting-items`）
